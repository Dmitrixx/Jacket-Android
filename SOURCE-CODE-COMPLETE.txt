# Changelog

## 2.8.0

- Consolidated native Filmix and HDRezka search/player adapters, encrypted account state, provider diagnostics and the unified detail-card source picker.
- Added the native optional Jackett indexer catalogue, dynamic per-indexer configuration/testing, private-indexer support and richer torrent release cards. Jackett remains user-managed and is not bundled.
- Added a ten-provider catalogue in priority order. Only Filmix and HDRezka have direct adapters; ColdFilm, Baskino, Kinogo, VideoCDN, Collaps, Kinobase, CDNMovies and Lordfilm remain unconnected descriptors pending a compatible verified integration.
- Added completion-order partial tracker results, bounded detail-page resolution, a 25-second aggregate deadline and protection against stale search callbacks.
- Restricted built-in HTML tracker requests, redirects and parsed download URLs to public HTTPS targets, including non-public IPv6 rejection. DNS rebinding is not fully prevented.
- Made initial torrent byte-range failures retryable with a sanitized HTTP 503 and Retry-After header before a successful response is committed.
- Hardened torrent persistence with bounded validation, per-record queue recovery, legacy migration, serialized resume checkpoints and AtomicFile backup recovery.
- Preserved saveable state across main, details, settings, downloads, player and individual navigation tabs.

## 2.7.0

- Fullscreen cinema player for phone and Android TV. Controls sit on top of the video and hide while playback continues.
- D-pad left/right seeks by 10 seconds when the overlay is hidden. Back hides the overlay first, then leaves the player. Center and media keys play and pause.
- Playback speed from 0.5× to 2×, picture fit / fill / zoom, and a sleep timer at 15, 30, 45 and 60 minutes. Speed and fit are remembered on the device.
- Phone picture-in-picture so a title can stay on screen after leaving Jacket. The player keeps the activity across rotation and PiP.
- Seek bar, elapsed time and remaining time in the overlay. Tap the left or right side of a hidden player to jump 10 seconds.
- Continue watching now shows the remaining time from the saved position.
- Includes the previously unreleased fixes already on main: bounded HDRezka page preview, Filmix device-authorization diagnostics, and explicit in-app torrent search on movie and episode cards.
- Picture-in-picture state is observed through the activity callback, so the build does not depend on an ActivityX type missing from this SDK line.

## 2.6.0

- Added a Lampa-style source picker sheet that opens automatically from movie and episode playback actions.
- Replaced global sequential torrent mode during playback with HTTP Range-driven piece deadlines, starting at the exact requested byte position.
- Added an ordered forward prefetch window capped at 8 MiB / 32 pieces; seek requests move the priority window instead of restarting from byte zero.
- Added a 32 MiB LRU disk ring for recently served byte ranges, including overlapping-range reuse and automatic eviction.
- Kept playback cache buffers bounded to 256 KiB per active stream worker; cache eviction never deletes verified torrent payload data.
- Added JVM tests for range-to-piece mapping, prefetch bounds, LRU eviction, overlapping byte-range hits and loopback Range delivery.

## 2.5.0

- Added an optional Jackett connector for a user-managed LAN or HTTPS server.
- Added `t=caps` connectivity checks, indexer filter selection and tracker attribution in source results.
- Improved Torznab parsing for Jackett tracker tags, comments, sizes, total peers and API error responses.
- Added a strict local-network HTTP policy; public indexers continue to require HTTPS.
- Enabled authenticated .torrent downloads from a local Jackett endpoint with origin-restricted credentials and redirect handling.
- Increased ExoPlayer's read timeout for loopback torrent streams so slow swarms have time to provide requested pieces.
- Preserved the existing in-process libtorrent engine, tokenized loopback stream server, Filmix pairing, HDRezka settings and built-in tracker shortcuts.

## Compatibility notes

- Jackett is not bundled and is not required. Direct RSS/Atom and Torznab sources continue to work without it.
- The uploaded Jacket 2.1.0 source set was not copied over the current application wholesale. Older duplicate torrent server, player, activity, manifest and Gradle files were superseded by newer implementations in the current main branch. Compatible Jackett functionality was merged into the current architecture instead.

# Jacket — Android media center 2.7.0

Jacket is a single Android application for phones, tablets and Android TV / Google TV. It combines a poster-based media catalog, a user-configurable indexer cabinet, an integrated BitTorrent engine and a loopback HTTP media server.

**No separately installed Jackett or TorrServer is required.** Neither service is bundled or launched by Jacket. Direct RSS/Atom and Torznab indexers work independently; an optional connector can also query a Jackett server that the user already runs on a LAN or HTTPS endpoint. Torrent files are handled by the in-process libtorrent4j session and served to ExoPlayer through `127.0.0.1`.

The project is under active development. CI verifies JVM unit tests and APK assembly; real-device streaming, Android TV remote navigation and process-kill recovery still require hands-on acceptance testing.

## Main areas

- **Home / Movies / Series** — poster shelves and grids, ratings, years and details.
- **Search** — catalog search with a short debounce; configurable website-search shortcuts open the matching query in the external browser.
- **Series details** — TMDB seasons and episode lists; an episode search adds its `SxxExx` code to the indexer query.
- **My library** — favorites and recently opened cards.
- **Sources** — manual search, indexer management, connectivity tests, source errors and quality filters.
- **Downloads** — magnet and `.torrent` tasks, file list, selected-file priorities, pause/resume, speed and progress.
- **Player** — fullscreen Media3 / ExoPlayer for phone and Android TV: overlay controls, 10-second seek, speed, fit/fill/zoom, sleep timer, audio and subtitle selection, picture-in-picture, sidecar subtitles, external-player handoff, progressive video, HLS and DASH.
- **Settings** — LAMPA-inspired control center for Filmix device-code pairing, HDRezka account/session, built-in tracker shortcuts, torrent indexers, catalog metadata and network limits.

## Filmix and HDRezka accounts

- **Filmix** uses a device-code flow: Jacket requests a short-lived code, the user confirms it on the Filmix device page, and the app polls for activation. The permanent device token is encrypted using Android Keystore. No Filmix password is requested.
- **HDRezka** has HTTPS mirror, email/login, password and manual Cookie-session fields. The app attempts the normal site sign-in and saves returned cookies encrypted using Android Keystore. If a mirror presents CAPTCHA, Cloudflare or an interactive browser challenge, Jacket stops and does not attempt to bypass it; a session cookie can be entered manually after signing in through the user's regular browser.
- Credentials and cookies stay on the device and are not included in diagnostics or tracker exports.

Filmix search includes catalogue results, translations, series episodes and plan-aware quality options; expiring CDN references are refreshed by the adapter. HDRezka search uses the current DLE AJAX form request and supports only the known player payload/quality formats. Unknown or rotated encodings fail closed. HDRezka uses the user-configured HTTPS mirror; there is no automatic mirror rotation or cross-origin Cookie forwarding. These flows still require real-device/network acceptance tests.

## Built-in tracker search

The first run seeds search shortcuts for RuTracker, NNM-Club, Rutor, Kinozal, 1337x, The Pirate Bay and Internet Archive. Jacket includes in-app HTML result parsers for RuTracker, NNM-Club, Rutor, Kinozal, 1337x and The Pirate Bay. Matching magnets and direct .torrent links are shown in the native release list and can be queued or opened in the built-in player. Internet Archive uses its structured metadata API.

Tracker pages can change markup or require an account, CAPTCHA, Cloudflare or another anti-bot challenge. User-supplied Cookie sessions are stored encrypted and sent only to the configured tracker origin. Jacket does not solve challenges or bypass access controls. Other user-added website shortcuts remain ordinary browser links.

## Video source catalogue

The source picker keeps the requested priority order: HDRezka, Filmix, ColdFilm, Baskino, Kinogo, VideoCDN, Collaps, Kinobase, CDNMovies and Lordfilm. Direct search/player adapters are implemented for Filmix and HDRezka. The other eight entries are catalogue descriptors only and remain visibly unconnected until a compatible, verified API or feed adapter is available. No live connector is claimed for Kinogo or Lordfilm.

## Indexer cabinet and optional Jackett connector

Add user-owned endpoints:

- RSS / Atom feeds and Torznab / Newznab-compatible endpoints over HTTPS.
- HTTP endpoints only when they target a private / loopback / link-local IP or a local DNS suffix such as `.local` or `.lan`; this is intended for a Jackett server on your own network.
- An optional Jackett setup card with server address, API key, tracker filter (`all` by default), connection test and disconnect. Jacket probes Jackett with `t=caps`, then searches its selected tracker set. Jackett remains external and is never installed or bundled.
- API key, HTTP Basic username/password, or a manually supplied session cookie.
- Categories, tags, Freeleech flag, sort field and sort order.
- Enable/disable, edit, individual test, test all and a per-indexer probe search.

A search runs enabled providers in parallel with at most four concurrent requests. A failed provider is reported by name and does not cancel successful peers. Feed responses are limited to 4 MiB, 100 entries per feed and 200 merged results. Connection and read timeouts are 10 and 25 seconds.

Indexer settings can be exported/imported as JSON. **API keys, passwords and cookies are deliberately omitted from exports** and must be entered again after import. Locally stored secrets are encrypted with Android Keystore using AES/GCM.

Example Torznab search template:

```text
https://your-authorized-indexer.example/api?t=search&q={query}
```

Search templates include `{query}`; `{apikey}` is optional. Public indexers must use HTTPS. The adapter understands common Torznab attributes including magnet URL, seeders, peers, size/length, category, Jackett's original tracker name and Torznab error responses. Jackett's `peers` value is treated as total peers; leechers are calculated as peers minus seeders. RSS/Atom enclosures and Media RSS `media:content` may also publish direct HTTPS video URLs (`video/*`, MP4/WebM/MKV), HLS playlists (`.m3u8`) or DASH manifests (`.mpd`). Jacket recognizes those declared media links and plays them directly in Media3; it does not need to inspect arbitrary pages.

Release labels such as 720p / 1080p / 2160p, HDR / DV, HEVC / x264 and common audio/dubbing tags are extracted heuristically from the release title. They are not authoritative tracker metadata. Filters operate on the current results and do not issue another request.

The app does not ship tracker credentials. The built-in tracker adapters parse supported listing/detail markup only; user-added website shortcuts remain browser links. CAPTCHA, anti-bot challenges, proprietary sign-in flows and interactive 2FA are not automated. A manually entered cookie may work where the source permits it.

## User-configured website search

Add up to 50 website search shortcuts with a name and an HTTPS URL template containing `{query}`. When a title is opened, Jacket shows an LAMPA-style source sheet; choosing a configured website opens its search URL in the external browser with the title and year encoded safely.

Example template shape:

```text
https://your-authorized-site.example/search?q={query}
```

Website shortcuts remain link-based and open the site in the browser. Structured in-app playback is supported when a source explicitly publishes a direct HTTPS media URL in an RSS/Atom enclosure or Media RSS `media:content`. Jacket does not scrape arbitrary HTML pages, unpack obfuscated player scripts, automate private logins or CAPTCHA, extract hidden streams, bypass DRM, or circumvent regional access restrictions. Use only services and media you are authorized to access. For a licensed provider, prefer its documented API or feed.

## Torrent engine and local stream server

The app uses one in-process libtorrent4j session:

1. Add a magnet or import a `.torrent` file from the app picker, Android Share, or an HTTPS result.
2. After metadata arrives, inspect the files in the torrent.
3. Select one file to watch. Jacket gives it the highest file priority, marks the other files `IGNORE`, enables sequential download and raises priority for the first pieces and the final piece.
4. ExoPlayer requests the selected file from the local HTTP server while libtorrent is still downloading the required pieces.

The local endpoint:

- Binds only to `127.0.0.1`, using port 8090–8099.
- Supports `GET`, `HEAD`, byte `Range`, `206 Partial Content`, `Content-Range`, `Accept-Ranges` and MIME types based on the filename.
- Parses the requested byte range and maps it to torrent piece indices using the file's absolute offset and the torrent piece length.
- Gives the first missing piece the nearest deadline, then schedules a forward window with increasing deadlines (up to 8 MiB / 32 pieces). A seek replaces the old window and starts prioritizing from the new Range position.
- Waits for the requested pieces to be hash-checked and written to disk before serving those bytes; it does not wait for the entire file.
- Uses a bounded 32 MiB LRU disk ring for recently served byte ranges. Individual segments are at most 256 KiB, overlapping seeks can reuse cached suffixes, and the oldest cache entries are evicted as the ring fills.
- Keeps the number of in-flight stream buffers bounded (one segment per active HTTP worker); it never allocates the full video in RAM.
- The temporary playback cache contains copies only. Evicting cached bytes never deletes libtorrent's verified torrent data, so the torrent's on-disk integrity and fast-resume state remain intact.
- Rejects non-loopback Host headers, malformed hashes, invalid file indices and traversal-like routes.
- Is not exposed to the home network or LAN.

The download queue and the native resume data are stored in app-private storage. Resume data is requested periodically and on pause; the queue retains the magnet or private copy of the `.torrent` so a task can be recreated if no resume file exists. Startup restores queued tasks when the app/service starts. A hard process kill can lose work since the most recent resume-data save; this is not a guarantee of crash-proof zero-loss recovery.

Downloaded files remain in the app-specific `Downloads` directory. “Remove from queue” preserves downloaded data. Deleting data is a separate, explicit action.

### Playback and foreground service

- ExoPlayer plays the torrent through the loopback Range endpoint before the download reaches 100%.
- Direct Internet Archive video playback remains HTTPS and is offered only when the source metadata contains a recognized Creative Commons / public-domain license URL. Review the source item's actual terms.
- Playback position is stored locally every few seconds; a torrent position is keyed by infohash and file index, and a direct stream position by a non-reversible URL hash. Positions at or beyond about 90% of a known duration are cleared.
- Audio and text tracks can be selected from those available in the media. A matching `.srt` / `.vtt` file already fully downloaded in the same torrent can be offered as a sidecar subtitle.
- The player is fullscreen. Overlay controls hide during playback. D-pad left/right seeks 10 seconds while the overlay is hidden; Back dismisses the overlay before leaving the player. Speed (0.5×–2×) and fit / fill / zoom are remembered on the device. A sleep timer can stop playback after 15, 30, 45 or 60 minutes. Phones can enter picture-in-picture. The screen stays awake and can hand the loopback URL to an external player.

While watching a torrent, the service uses foreground-service type `mediaPlayback`. Background downloading uses `dataSync`. Android 15+ applies a cumulative time limit to `dataSync`; when that limit is reached without active playback, Jacket saves resume data and stops the background session. **Uninterrupted all-day downloading or seeding is not promised.** Reopen Jacket to restore the queued work.

## Android TV

The same APK declares Leanback support as optional and touchscreen as not required. Android TV / Google TV has a Leanback launcher entry and banner, a navigation rail, larger poster cards, visible focus states and D-pad navigation. The fullscreen player handles Back, play/pause and left/right seeking without requiring a touchscreen.

The JVM test suite covers:

# Security Policy

## Supported versions

Security fixes target the latest commit on `main`. There is no stable release yet.

## Reporting a vulnerability

Do not publish access tokens, private indexer credentials, personal data, or a working exploit in a public issue.

Use GitHub's **Report a vulnerability** flow in the repository Security tab when available. Otherwise contact the maintainer privately through a verified GitHub contact channel. Include the affected commit, Android version/device ABI, reproduction steps and impact. Remove secrets from logs.

## Security design

- The optional TMDB Read Access Token is encrypted with AES/GCM using a key held in Android Keystore.
- Public RSS/Atom and Torznab indexers must use HTTPS. Cleartext HTTP is allowed only for private/loopback/link-local IPs and explicit local DNS suffixes; ambiguous single-label hosts and URL user-info are rejected.
- Network requests have bounded response sizes and timeouts.
- XML document type declarations are disabled in feed parsing.
- Remote poster and media URLs are restricted to HTTPS.
- Android backup is disabled to avoid copying private app settings to cloud backup.
- Jackett credentials are encrypted at rest. For a local Jackett source, the API key is sent only to that configured local origin; redirects must remain on the same local HTTP origin or upgrade to HTTPS, and authorization headers are never forwarded to a different origin.
- Direct torrent links are treated as untrusted source data. Verify the publisher and license before opening or downloading content.

## User guidance

Do not share private indexer credentials or add feeds from sources you do not trust. Jackett is optional and is never bundled. When used, connect only to a server you control or are authorized to access. Use only catalogs and media streams you have permission to access.

    private fun handleIncomingIntent(incoming: Intent?) {
        if (incoming == null) return
        val sharedText = when (incoming.action) {
            Intent.ACTION_VIEW -> incoming.dataString
            Intent.ACTION_SEND -> incoming.getStringExtra(Intent.EXTRA_TEXT)
            else -> null
        }?.trim().orEmpty()

        val magnet = Regex("magnet:\\?[^\\s]+", RegexOption.IGNORE_CASE).find(sharedText)?.value
        if (magnet != null) {
            val title = runCatching { Uri.parse(magnet).getQueryParameter("dn") }
                .getOrNull()?.takeIf { it.isNotBlank() } ?: "Magnet-загрузка"
            TorrentDownloadService.add(applicationContext, magnet, title)
            Toast.makeText(this, "Торрент добавлен в Jacket", Toast.LENGTH_SHORT).show()
            return
        }

        val sharedUri = when (incoming.action) {
            Intent.ACTION_VIEW -> incoming.data
            Intent.ACTION_SEND -> if (android.os.Build.VERSION.SDK_INT >= 33) {
                incoming.getParcelableExtra(Intent.EXTRA_STREAM, Uri::class.java)
            } else {
                @Suppress("DEPRECATION")
                incoming.getParcelableExtra(Intent.EXTRA_STREAM) as? Uri
            }
            else -> null
        }
        val remoteTorrent = sharedText.takeIf {
            runCatching { Uri.parse(it).scheme == "https" && Uri.parse(it).path.orEmpty().endsWith(".torrent", true) }.getOrDefault(false)
        }
        if (remoteTorrent != null) {
            TorrentDownloadService.addTorrentUrl(applicationContext, remoteTorrent, "Торрент-файл")
            Toast.makeText(this, "Загружаю .torrent в Jacket", Toast.LENGTH_SHORT).show()
            return
        }
        if (sharedUri != null) {
            importTorrentUri(sharedUri)
        }
    }

    private fun importTorrentUri(uri: Uri) {
        Thread {
            val result = runCatching {
                val directory = File(filesDir, "torrent-imports").apply { mkdirs() }
                val name = contentResolver.query(uri, null, null, null, null)?.use { cursor ->
                    val column = cursor.getColumnIndex(OpenableColumns.DISPLAY_NAME)
                    if (column >= 0 && cursor.moveToFirst()) cursor.getString(column) else null
                }?.takeIf { it.endsWith(".torrent", true) } ?: "shared.torrent"
                val target = File.createTempFile("incoming_", ".torrent", directory)
                contentResolver.openInputStream(uri).use { input ->
                    requireNotNull(input) { "Не удалось открыть файл" }
                    target.outputStream().use { output ->
                        val buffer = ByteArray(8192)
                        var total = 0L
                        while (true) {
                            val count = input.read(buffer)
                            if (count < 0) break
                            total += count
                            require(total <= TorrentQueueStore.MAX_TORRENT_BYTES) { "Файл .torrent превышает 8 МиБ" }
                            output.write(buffer, 0, count)
                        }
                    }
                }
                target to name
            }
            runOnUiThread {
                result.onSuccess { (file, name) ->
                    TorrentDownloadService.addTorrentFile(applicationContext, file.absolutePath, name.removeSuffix(".torrent"))
                    Toast.makeText(this, ".torrent добавлен во встроенную очередь", Toast.LENGTH_SHORT).show()
                }.onFailure { error ->
                    Toast.makeText(this, "Не удалось импортировать .torrent: ${error.message}", Toast.LENGTH_LONG).show()
                }
            }
        }.start()
    }
}

fun openTorrent(context: Context, entry: TorrentEntry) {
    val target = entry.openUri
    if (target.isNullOrBlank()) {
        Toast.makeText(context, "Для этого результата нет magnet-ссылки или URL", Toast.LENGTH_LONG).show()
        return
    }

    val intent = Intent(Intent.ACTION_VIEW, Uri.parse(target)).addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
    try {
        context.startActivity(Intent.createChooser(intent, "Открыть торрент через…").addFlags(Intent.FLAG_ACTIVITY_NEW_TASK))
    } catch (_: Exception) {
        copyToClipboard(context, target)
        Toast.makeText(context, "Подходящий торрент-клиент не найден. Ссылка скопирована.", Toast.LENGTH_LONG).show()
    }
}

package app.jacket.mobile.data

import java.io.IOException
import java.util.concurrent.Callable
import java.util.concurrent.ExecutorCompletionService
import java.util.concurrent.Executors
import java.util.concurrent.TimeUnit

/**
 * Consumes concurrent work as soon as each task finishes and cancels unfinished
 * tasks after a shared deadline. One slow request cannot block already-completed work.
 */
internal object CompletionOrderCollector {
    fun <T> collect(
        tasks: List<Callable<T>>,
        timeoutMs: Long,
        maxConcurrency: Int,
        onResult: (Result<T>) -> Unit
    ): Int {
        if (tasks.isEmpty()) return 0
        require(timeoutMs > 0L) { "Timeout must be positive" }
        require(maxConcurrency > 0) { "Concurrency must be positive" }

        val executor = Executors.newFixedThreadPool(minOf(maxConcurrency, tasks.size))
        val completion = ExecutorCompletionService<T>(executor)
        val futures = tasks.map { task -> completion.submit(task) }
        val deadline = System.nanoTime() + TimeUnit.MILLISECONDS.toNanos(timeoutMs)
        var completed = 0
        try {
            while (completed < tasks.size) {
                val remainingNanos = deadline - System.nanoTime()
                if (remainingNanos <= 0L) break
                val future = completion.poll(remainingNanos, TimeUnit.NANOSECONDS) ?: break
                val result = try {
                    Result.success(future.get())
                } catch (error: Exception) {
                    Result.failure(error.cause ?: error)
                }
                completed++
                onResult(result)
            }
        } catch (interrupted: InterruptedException) {
            Thread.currentThread().interrupt()
            throw IOException("Ожидание параллельных запросов прервано", interrupted)
        } finally {
            futures.filterNot { it.isDone }.forEach { it.cancel(true) }
            executor.shutdownNow()
        }
        return completed
    }
}

data class FilmixQualityVariant(

/**
 * Direct Filmix v2 client authenticated with the user's device token.
 *
 * It deliberately uses only the API base explicitly selected in settings:
 * no mirror discovery, proxy, cleartext fallback or TLS relaxation.
 */
object FilmixCatalogClient {
    private const val MAX_RESPONSE_BYTES = 4 * 1024 * 1024
    private const val MAX_SEARCH_ITEMS = 8
    private const val MAX_TRANSLATIONS = 12
    private const val MAX_EPISODES_PER_SEASON = 100
    private const val USER_AGENT = "JacketAndroid/2.7 (Filmix v2 client)"
    private const val LIVEHASH_POST_ID = 171042
    private const val LIVEHASH_TTL_MS = 2 * 60 * 60 * 1000L
    private val livehashPattern = Regex("/s/([^/]+)/")
    @Volatile private var cachedLivehash: String? = null
    @Volatile private var cachedLivehashKey: String? = null
    @Volatile private var livehashExpiresAt = 0L
    private val livehashLock = Any()
    private val qualityListPattern = Regex("_\\[([0-9,]+)]\\.mp4", RegexOption.IGNORE_CASE)
    private val qualityPlaceholderPattern = Regex("_%s\\.mp4", RegexOption.IGNORE_CASE)
    private val episodeCodePattern = Regex("(?i)S(\\d{1,2})E(\\d{1,3})")

    fun searchSources(
        apiBase: String,
        deviceId: String,
        token: String,
        query: String,
        kind: MediaKind,
        episodeCode: String? = null
    ): List<SourceResult> {
        require(query.isNotBlank()) { "Введите название для поиска Filmix" }
        require(token.isNotBlank()) { "Сначала привяжите устройство Filmix" }
        val safeBase = FilmixDeviceAuth.normalizeApiBase(apiBase)
        val safeDeviceId = deviceId.takeIf { it.matches(Regex("[a-fA-F0-9]{16}")) }
            ?: throw IllegalArgumentException("Некорректный ID устройства Filmix")

        val searchJson = getJson(
            buildApiUrl(safeBase, "search", safeDeviceId, token, mapOf("story" to query.trim().take(160)))
        )
        val entries = parseSearchEntries(searchJson)
            .asSequence()
            .filter { when (kind) {
                MediaKind.MOVIE -> !it.isSeries
                MediaKind.SERIES -> it.isSeries
                MediaKind.VIDEO -> true
            } }
            .distinctBy { it.id }
            .take(MAX_SEARCH_ITEMS)
            .toList()
        if (entries.isEmpty()) return emptyList()

        val maxQuality = loadMaxQuality(safeBase, safeDeviceId, token)
        val parsed = buildList {
            entries.forEach { entry ->
                val post = runCatching {
                    getJson(buildApiUrl(safeBase, "post/${entry.id}", safeDeviceId, token))
                }.getOrNull() ?: return@forEach
                addAll(
                    parsePostSources(
                        post = post,
                        entry = entry,
                        episodeCode = episodeCode,
                        maxQuality = maxQuality
                    )
                )
            }
        }.distinctBy { it.id }.take(80)

        // Some Filmix CDN URLs contain a rotating /s/{livehash}/ prefix. Refresh
        // it from the public reference post only when a selected result needs it.
        if (parsed.none { livehashPattern.containsMatchIn(it.streamUrl.orEmpty()) }) return parsed
        val livehash = getLivehash(safeBase, safeDeviceId, token) ?: return parsed
        return parsed.map { source ->
            val url = source.streamUrl ?: return@map source
            source.copy(streamUrl = replaceLivehash(url, livehash))
        }
    }

    internal fun buildApiUrl(
        apiBase: String,
        endpoint: String,
        deviceId: String,
        token: String,
        query: Map<String, String> = emptyMap()
    ): String = FilmixDeviceAuth.buildAuthenticatedApiUrl(apiBase, endpoint, deviceId, token, query)

    internal fun replaceLivehash(url: String, livehash: String): String {
        require(livehash.matches(Regex("[A-Za-z0-9_-]{1,128}"))) { "Некорректный Filmix livehash" }
        return livehashPattern.replace(url, "/s/$livehash/")
    }

    internal fun extractLivehash(post: JSONObject): String? =
        livehashPattern.find(post.toString())?.groupValues?.getOrNull(1)
            ?.takeIf { it.matches(Regex("[A-Za-z0-9_-]{1,128}")) }

    private fun getLivehash(apiBase: String, deviceId: String, token: String): String? {
        val cacheKey = "$apiBase|$deviceId"
        val now = System.currentTimeMillis()
        if (cachedLivehashKey == cacheKey && now < livehashExpiresAt) {
            cachedLivehash?.let { return it }
        }
        synchronized(livehashLock) {
            val lockedNow = System.currentTimeMillis()
            if (cachedLivehashKey == cacheKey && lockedNow < livehashExpiresAt) {
                cachedLivehash?.let { return it }
            }
            val post = runCatching {
                getJson(buildApiUrl(apiBase, "post/$LIVEHASH_POST_ID", deviceId, token))
            }.getOrNull() ?: return null
            val fresh = extractLivehash(post) ?: return null
            cachedLivehash = fresh
            cachedLivehashKey = cacheKey
            livehashExpiresAt = System.currentTimeMillis() + LIVEHASH_TTL_MS
            return fresh
        }
    }

    internal fun parseSearchEntries(json: JSONObject): List<FilmixSearchEntry> {
        val array = when {
            json.has("data") -> json.optJSONArray("data")
            json.has("results") -> json.optJSONArray("results")
            json.has("items") -> json.optJSONArray("items")
            else -> null
        } ?: JSONArray()
        return (0 until array.length()).mapNotNull { index ->
            val item = array.optJSONObject(index) ?: return@mapNotNull null
            val id = item.optInt("id").takeIf { it > 0 } ?: return@mapNotNull null
            val title = item.optString("title").trim().takeIf { it.isNotBlank() } ?: return@mapNotNull null
            val section = item.optInt("section", -1)
            val isSeries = section == 7
            val slug = item.optString("alt_name").trim()
            val page = slug.takeIf { it.matches(Regex("[\\p{L}\\p{N}._-]{1,180}")) }?.let {
                "${FilmixDeviceAuth.SITE_BASE}/${if (isSeries) "seria" else "film"}/$id-$it.html"
            }
            FilmixSearchEntry(
                id = id,
                title = title,
                originalTitle = item.optString("original_title").trim(),
                year = item.optInt("year").takeIf { it in 1888..2200 },
                isSeries = isSeries,
                pageUrl = page
            )
        }.take(100)
    }

    internal fun parsePostSources(
        post: JSONObject,
        entry: FilmixSearchEntry,
        episodeCode: String?,
        maxQuality: Int
    ): List<SourceResult> {
        val data = post.optJSONObject("data") ?: post
        val playerLinks = data.optJSONObject("player_links") ?: JSONObject()
        val title = data.optString("title").takeIf { it.isNotBlank() } ?: entry.title
        if (!entry.isSeries) {
            val movies = playerLinks.optJSONArray("movie") ?: JSONArray()
            return buildList {
                for (i in 0 until minOf(movies.length(), MAX_TRANSLATIONS)) {
                    val translation = movies.optJSONObject(i) ?: continue
                    val name = translation.optString("translation").ifBlank { "Оригинал" }
                    val link = translation.optString("link")
                    addAll(
                        variantsToSources(
                            entry = entry,
                            title = title,
                            translation = name,
                            link = link,
                            explicitQualities = translation.optJSONArray("qualities"),
                            maxQuality = maxQuality,
                            episodeCode = null
                        )
                    )
                }
            }
        }

        val episodeMatch = episodeCodePattern.find(episodeCode.orEmpty())
        if (episodeMatch == null) {
            val translations = linkedSetOf<String>()
            val playlist = playerLinks.optJSONObject("playlist") ?: JSONObject()
            val seasonKeys = playlist.keys()
            while (seasonKeys.hasNext() && translations.size < MAX_TRANSLATIONS) {
                val season = playlist.optJSONObject(seasonKeys.next()) ?: continue
                val names = season.keys()
                while (names.hasNext() && translations.size < MAX_TRANSLATIONS) translations += names.next()
            }
            return translations.map { translation ->
                SourceResult(
                    id = "filmix:${entry.id}:$translation",
                    title = title,
                    providerName = "Filmix",
                    pageUrl = entry.pageUrl,
                    sourceType = MediaSourceType.FILMIX,
                    translationName = translation
                )
            }
        }

        val wantedSeason = episodeMatch.groupValues[1].toIntOrNull() ?: return emptyList()
        val wantedEpisode = episodeMatch.groupValues[2].toIntOrNull() ?: return emptyList()
        val playlist = playerLinks.optJSONObject("playlist") ?: return emptyList()
        val season = playlist.optJSONObject(wantedSeason.toString()) ?: return emptyList()
        return buildList {
            val translations = season.keys()
            var count = 0
            while (translations.hasNext() && count++ < MAX_TRANSLATIONS) {
                val translationName = translations.next()
                val value = season.opt(translationName)
                val episode = findEpisode(value, wantedEpisode) ?: continue
                addAll(
                    variantsToSources(
                        entry = entry,
                        title = "$title • $episodeCode",
                        translation = translationName,
                        link = episode.optString("link"),
                        explicitQualities = episode.optJSONArray("qualities"),
                        maxQuality = maxQuality,
                        episodeCode = episodeCode
                    )
                )
            }
        }
    }

    internal fun parseQualityVariants(link: String, explicitQualities: JSONArray? = null): List<FilmixQualityVariant> {
        val safeLink = link.trim()
        if (safeLink.isBlank()) return emptyList()
        val parsedQualities = buildSet {
            if (explicitQualities != null) {
                for (index in 0 until explicitQualities.length()) {
                    val quality = explicitQualities.optInt(index).takeIf { it in 144..4320 }
                    if (quality != null) add(quality)
                }
            }
            qualityListPattern.find(safeLink)?.groupValues?.getOrNull(1)
                ?.split(',')
                ?.mapNotNull { it.toIntOrNull()?.takeIf { q -> q in 144..4320 } }
                ?.forEach(::add)
        }.sortedDescending()

        if (parsedQualities.isNotEmpty()) {
            return parsedQualities.mapNotNull { quality ->
                val resolved = when {
                    qualityListPattern.containsMatchIn(safeLink) ->
                        qualityListPattern.replace(safeLink, "_$quality.mp4")
                    qualityPlaceholderPattern.containsMatchIn(safeLink) ->
                        qualityPlaceholderPattern.replace(safeLink, "_$quality.mp4")
                    else -> safeLink
                }
                resolved.takeIf(::isHttpsUrl)?.let { FilmixQualityVariant(quality, it) }
            }
        }
        if (qualityListPattern.containsMatchIn(safeLink) || qualityPlaceholderPattern.containsMatchIn(safeLink)) {
            return emptyList()
        }
        return listOfNotNull(safeLink.takeIf(::isHttpsUrl)?.let { FilmixQualityVariant(null, it) })
    }

    internal fun maxQualityFromProfile(profile: JSONObject): Int {
        fun flag(name: String): Boolean {
            val value = profile.opt(name)
            return when (value) {
                is Boolean -> value
                is Number -> value.toInt() != 0
                is String -> value == "1" || value.equals("true", true)
                else -> false
            }
        }
        return when {
            flag("is_pro_plus") -> 2160
            flag("is_pro") -> 1080
            else -> 720
        }
    }

    private fun variantsToSources(
        entry: FilmixSearchEntry,
        title: String,
        translation: String,
        link: String,
        explicitQualities: JSONArray?,
        maxQuality: Int,
        episodeCode: String?
    ): List<SourceResult> {
        val variants = parseQualityVariants(link, explicitQualities)
        if (variants.isEmpty()) return emptyList()
        val eligible = variants.filter { it.quality == null || it.quality <= maxQuality }
        return eligible.map { variant ->
            val qualityText = variant.quality?.let { "${it}p" }
            SourceResult(
                id = "filmix:${entry.id}:${episodeCode.orEmpty()}:$translation:${variant.quality ?: "auto"}",
                title = title,
                providerName = "Filmix",
                streamUrl = variant.url,
                pageUrl = entry.pageUrl,
                sourceType = MediaSourceType.FILMIX,
                qualityLabel = qualityText,
                translationName = translation,
                requestHeaders = mapOf(
                    "Referer" to (entry.pageUrl ?: FilmixDeviceAuth.SITE_BASE),
                    "User-Agent" to USER_AGENT
                )
            )
        }
    }

    private fun findEpisode(value: Any?, episodeNumber: Int): JSONObject? = when (value) {
        is JSONArray -> value.optJSONObject(episodeNumber - 1)
        is JSONObject -> value.optJSONObject(episodeNumber.toString())
            ?: value.optJSONObject(episodeNumber.toString().padStart(2, '0'))
        else -> null
    }

    private fun loadMaxQuality(apiBase: String, deviceId: String, token: String): Int = runCatching {

    private fun getJson(requestUrl: String): JSONObject {
        val uri = URI(requestUrl)
        require(uri.scheme.equals("https", true) && uri.host in setOf("filmixapp.cyou", "fxapp.biz")) {
            "API Filmix должен использовать выбранный HTTPS-сервер"
        }
        val connection = (URL(requestUrl).openConnection() as HttpURLConnection).apply {
            requestMethod = "GET"
            connectTimeout = 8_000
            readTimeout = 15_000
            instanceFollowRedirects = false
            setRequestProperty("Accept", "application/json")
            setRequestProperty("User-Agent", USER_AGENT)
        }
        try {
            val status = connection.responseCode
            if (status !in 200..299) {
                throw IOException("Filmix API: HTTP $status (${uri.host}, ${uri.path})")
            }
            val declaredSize = connection.getHeaderFieldLong("Content-Length", -1L)
            require(declaredSize <= MAX_RESPONSE_BYTES) { "Ответ Filmix API слишком большой" }
            val bytes = connection.inputStream.use { input ->
                val output = ByteArrayOutputStream()
                val buffer = ByteArray(8192)
                while (true) {
                    val count = input.read(buffer)
                    if (count < 0) break
                    if (output.size() + count > MAX_RESPONSE_BYTES) throw IOException("Ответ Filmix API слишком большой")
                    output.write(buffer, 0, count)
                }
                output.toByteArray()
            }
            val parsed = JSONTokener(bytes.toString(Charsets.UTF_8)).nextValue()
            if (parsed is JSONObject) return parsed
            if (parsed is JSONArray) return JSONObject().put("data", parsed)
            throw IOException("Filmix API вернул неожиданный JSON")
        } finally {
            connection.disconnect()
        }
    }

    private fun isHttpsUrl(value: String): Boolean = runCatching {
        val uri = URI(value)
        uri.scheme.equals("https", true) && !uri.host.isNullOrBlank() && uri.rawUserInfo == null
    }.getOrDefault(false)

            "user_dev_vendor" to API_DEVICE_VENDOR,

            params[key] = value.take(300)
        }
        return safeBase + "/" + endpoint.trimStart('/') + "?" +

    private fun describeFailure(error: Throwable): String {
        val chain = generateSequence(error) { it.cause }.take(8).toList()
        return when {
            chain.any { it is javax.net.ssl.SSLPeerUnverifiedException } ->
                "TLS: сертификат не соответствует имени домена"
            chain.any { it is java.security.cert.CertificateExpiredException } ->
                "TLS: срок действия сертификата истёк"
            chain.any {
                it is java.security.cert.CertificateException ||
                    it is java.security.cert.CertPathValidatorException
            } -> "TLS: цепочка сертификатов не доверена или неполная"
            chain.any { it is javax.net.ssl.SSLException } ->
                "TLS: ошибка рукопожатия или сертификата"
            chain.any { it is java.net.UnknownHostException } -> "ошибка DNS"
            chain.any { it is java.net.SocketTimeoutException } -> "тайм-аут"
            else -> error.message
                ?.replace(Regex("[\\r\\n\\t]+"), " ")
                ?.take(120)
                ?.ifBlank { error.javaClass.simpleName }
                ?: error.javaClass.simpleName
        }
    }

    private fun readLimited(input: java.io.InputStream, maxBytes: Int): ByteArray {
        input.use { source ->
            val output = ByteArrayOutputStream()
            val buffer = ByteArray(8_192)
            while (true) {
                val count = source.read(buffer)
                if (count < 0) break
                if (output.size() + count > maxBytes) throw IOException("Ответ Filmix слишком большой")
                output.write(buffer, 0, count)
            }
            return output.toByteArray()
        }
    }

    /** Hide raw certificate diagnostics while preserving safe per-host API status details. */
    fun userFriendlyError(error: Throwable): String {
        val message = error.message.orEmpty()
        // Preserve safe per-host information even when the cause is an SSLException.
        if (message.startsWith("Filmix API недоступен по HTTPS")) {
            return message.replace(Regex("[\\r\\n\\t]+"), " ").take(320)
        }
        val chain = generateSequence(error) { it.cause }.take(8).toList()
        if (chain.any {
                it is javax.net.ssl.SSLHandshakeException ||
                    it is javax.net.ssl.SSLPeerUnverifiedException ||
                    it is javax.net.ssl.SSLException
            } || chain.any {
                it.message.orEmpty().contains("not verified", ignoreCase = true) ||
                    it.message.orEmpty().contains("certificate", ignoreCase = true)
            }
        ) {
            return "Filmix API: ошибка проверки HTTPS-сертификата. Проверьте адрес API или попробуйте позже."
        }
        return message.replace(Regex("[\\r\\n\\t]+"), " ").take(240)
            .ifBlank { "Не удалось подключить Filmix" }
    }

    private fun encode(value: String): String =
        URLEncoder.encode(value, Charsets.UTF_8.name()).replace("+", "%20")
}

    internal fun parseSearchEntries(html: String, mirror: String): List<HdRezkaSearchEntry> {

        fun toEntry(anchor: org.jsoup.nodes.Element, container: org.jsoup.nodes.Element?): HdRezkaSearchEntry? {
            val pageUrl = anchor.absUrl("href")
                .takeIf { it.isNotBlank() && isSameOrigin(it, mirror) }
                ?: return null

            if (!isLikelyMediaPage(path)) return null
            val title = anchor.selectFirst(".enty")?.text()?.trim()
                ?.takeIf { it.isNotBlank() }
                ?: anchor.attr("title").ifBlank { anchor.text() }.trim()
                    .takeIf { it.isNotBlank() }

                sequenceOf("src", "data-src", "data-original")
                    .map { element.absUrl(it) }
                    .firstOrNull(::isHttpsUrl)
            }

            return HdRezkaSearchEntry(title, pageUrl, poster, description)
        }

        val cardEntries = cards.mapNotNull { card ->
            val anchor = card.selectFirst(".b-content__inline_item-link a[href]")
                ?: card.selectFirst("a.b-content__inline_item-link[href]")
                ?: card.selectFirst("a[href]")
                ?: return@mapNotNull null
            toEntry(anchor, card)
        }
        if (cardEntries.isNotEmpty()) return cardEntries.distinctBy { it.pageUrl }.take(100)

    internal fun resolveEpisodeIds(
        response: JSONObject,
        wantedSeason: Int,
        wantedEpisode: Int,
        fallbackSeasonId: String? = null,
        fallbackEpisodeId: String? = null
    ): HdRezkaEpisodeIds? {

            .ifBlank { response.optJSONObject("data")?.optString("seasons").orEmpty() }

            .ifBlank { response.optJSONObject("data")?.optString("episodes").orEmpty() }

            else availableSeasonIds.getOrNull(wantedSeason - 1)
                ?: fallbackSeasonId?.takeIf(availableSeasonIds::contains)
                ?: return null

                element.attr("data-episode-number") == wantedEpisode.toString()

                fallbackEpisodeId?.matches(Regex("[0-9]{1,12}")) == true

        }

    internal fun decodeStreamPayload(raw: String): String? {
        val value = raw.trim()
        if (value.isBlank()) return null
        if (!value.startsWith("#")) return value
        if (value.length > MAX_OBFUSCATED_URL_CHARS || value.length < 4) return null

        var payload = value.substring(2)
        encodedTrashTokens.forEach { token ->
            payload = payload.replace("//_//$token", "")
        }
        val bytes = runCatching { Base64.getDecoder().decode(payload) }.getOrNull()
            ?: return null
        if (bytes.isEmpty() || bytes.size > MAX_OBFUSCATED_URL_CHARS) return null
        val decoded = bytes.toString(Charsets.UTF_8)
        if (decoded.any { it.isISOControl() && it != '\t' && it != '\r' && it != '\n' }) {
            return null
        }
        return decoded.takeIf { it.contains("https://", ignoreCase = true) }
    }

    internal fun parseQualityVariants(raw: String): List<HdRezkaQualityVariant> {
        val value = decodeStreamPayload(raw) ?: return emptyList()
        val parsed = value.split(',').mapNotNull { segment ->
            val match = qualityPattern.matchEntire(segment.trim()) ?: return@mapNotNull null
            val label = match.groupValues[1].trim().take(64)
            val urls = match.groupValues[2].split(Regex("""\s+or\s+"""))
                .map(String::trim)
                .filter(::isHttpsUrl)
            // Media3 handles both MP4 and HLS. Prefer a direct MP4 for seeking
            // compatibility, then HLS, then the first supported HTTPS fallback.
            val url = urls.firstOrNull { it.substringBefore('?').endsWith(".mp4", true) }
                ?: urls.firstOrNull { it.substringBefore('?').endsWith(".m3u8", true) }
                ?: urls.firstOrNull()
                ?: return@mapNotNull null
            val numericQuality = Regex("""(?i)([0-9]{3,4})""")
                .find(label)?.groupValues?.getOrNull(1)
            val normalizedLabel = numericQuality?.let { "${it}p" } ?: label
            HdRezkaQualityVariant(normalizedLabel, url)
        }.distinctBy { it.url }
        if (parsed.isNotEmpty()) return parsed
        val direct = directUrlPattern.find(value)?.value?.trim()?.trimEnd(')', ';')
        return listOfNotNull(direct?.takeIf(::isHttpsUrl)?.let {
            HdRezkaQualityVariant(null, it)
        })
    }

    internal fun parseSubtitles(data: JSONObject): List<MediaSubtitle> {
        val raw = data.optString("subtitle").ifBlank { data.optString("subtitles") }
        if (raw.isBlank()) return emptyList()
        val languages = data.optJSONObject("subtitle_lns") ?: JSONObject()
        val defaultLanguage = data.optString("subtitle_def").takeIf { it.isNotBlank() }
        val matcher = Regex("\\[([^\\]]+)](https://[^,\\s]+)", RegexOption.IGNORE_CASE)
        val parsed = matcher.findAll(raw).mapNotNull { m ->
            val language = m.groupValues[1].trim().take(12)
            val url = m.groupValues[2].trim()
            if (!isHttpsUrl(url)) return@mapNotNull null
            MediaSubtitle(
                url = url,
                mimeType = if (url.substringBefore('?').endsWith(".srt", true)) "application/x-subrip" else "text/vtt",
                language = language,
                label = languages.optString(language).takeIf { it.isNotBlank() } ?: language
            )
        }.toMutableList()
        if (parsed.isEmpty()) {
            directUrlPattern.find(raw)?.value?.let { url ->
                if (isHttpsUrl(url)) parsed += MediaSubtitle(
                    url = url,
                    mimeType = if (url.substringBefore('?').endsWith(".srt", true)) "application/x-subrip" else "text/vtt",
                    language = defaultLanguage,
                    label = defaultLanguage?.let { languages.optString(it).ifBlank { it } } ?: "Субтитры"
                )
            }
        }
        return parsed.distinctBy { it.url }.take(12)
    }

    private fun requestText(
        mirror: String,
        url: String,
        method: String,
        body: String?,
        referer: String,
        settings: HdRezkaSettings = HdRezkaSettings(),
        contentType: String? = null
    ): String {
        require(isSameOrigin(url, mirror)) { "HDRezka перенаправила запрос на другой домен; Cookie не отправлена." }
        var currentUrl = url
        var currentMethod = method
        var currentBody = body
        repeat(MAX_REDIRECTS + 1) {
            val requestBody = currentBody
            val uri = URI(currentUrl)
            val connection = (URL(currentUrl).openConnection() as HttpURLConnection).apply {
                requestMethod = currentMethod
                connectTimeout = 10_000
                readTimeout = 18_000
                instanceFollowRedirects = false
                setRequestProperty("Accept", "application/json, text/plain, */*")
                setRequestProperty("Accept-Language", "ru-RU,ru;q=0.9,en;q=0.8")
                setRequestProperty("Cache-Control", "no-cache")
                setRequestProperty("User-Agent", USER_AGENT)
                setRequestProperty("X-Requested-With", "XMLHttpRequest")
                setRequestProperty("Origin", mirror)
                setRequestProperty("Referer", referer)
                if (HdRezkaLoginClient.hasAuthenticatedCookie(settings.cookie) &&
                    uri.host.equals(URI(mirror).host, true)
                ) setRequestProperty("Cookie", settings.cookie)
                if (requestBody != null) {
                    doOutput = true
                    setRequestProperty("Content-Type", contentType ?: "application/x-www-form-urlencoded")
                }
            }
            try {
                if (requestBody != null) connection.outputStream.use { it.write(requestBody.toByteArray(Charsets.UTF_8)) }
                val status = connection.responseCode
                if (status in redirectCodes) {
                    val location = connection.getHeaderField("Location")
                        ?: throw IOException("HDRezka вернула перенаправление без адреса")
                    val next = URL(URL(currentUrl), location).toString()
                    if (!isSameOrigin(next, mirror)) {
                        throw IOException("HDRezka перенаправила запрос на другой домен. Автоматический переход запрещён.")
                    }
                    if (status in setOf(301, 302, 303)) {
                        currentMethod = "GET"
                        currentBody = null
                    }
                    currentUrl = next
                    return@repeat
                }
                val stream = if (status in 200..299) connection.inputStream else connection.errorStream
                val text = (stream?.use { readLimited(it, MAX_RESPONSE_BYTES) } ?: ByteArray(0)).toString(Charsets.UTF_8)
                if (status == 403 || HdRezkaLoginClient.containsBrowserChallenge(text)) {
                    throw IOException(
                        "HDRezka требует браузерную проверку или заблокировала прямой доступ. " +
                            "Jacket не обходит CAPTCHA/Anubis; откройте сайт обычным браузером."
                    )
                }
                if (status !in 200..299) throw IOException("HDRezka ответила HTTP $status на ${uri.path}")
                return text
            } finally {
                connection.disconnect()
            }
        }
        throw IOException("Слишком много перенаправлений HDRezka")
    }

    private fun readLimited(input: java.io.InputStream, maxBytes: Int): ByteArray {
        val output = ByteArrayOutputStream()
        val buffer = ByteArray(8192)
        while (true) {
            val count = input.read(buffer)
            if (count < 0) break
            if (output.size() + count > maxBytes) throw IOException("Ответ HDRezka слишком большой")
            output.write(buffer, 0, count)
        }
        return output.toByteArray()
    }

    private fun isSameOrigin(url: String, mirror: String): Boolean = runCatching {
        val target = URI(url)
        val base = URI(mirror)
        target.scheme.equals("https", true) && target.rawUserInfo == null &&
            target.host.equals(base.host, true) &&
            (if (target.port >= 0) target.port else 443) == (if (base.port >= 0) base.port else 443)
    }.getOrDefault(false)

    private fun isHttpsUrl(value: String): Boolean = runCatching {
        val uri = URI(value)
        uri.scheme.equals("https", true) && !uri.host.isNullOrBlank() && uri.rawUserInfo == null
    }.getOrDefault(false)

    private fun encode(value: String): String = URLEncoder.encode(value, Charsets.UTF_8.name())
}

data class HdRezkaLoginResult(
    val activeMirror: String,
    val cookieHeader: String

/**
 * Standard HTTPS sign-in for an HDRezka account.
 *
 * This client does not spoof TLS fingerprints, solve JavaScript challenges,
 * bypass CAPTCHA, or retry through proxy networks. If the site presents an
 * anti-bot challenge, sign-in is reported as unavailable and users may supply
 * their own session cookie obtained through the normal browser login.
 */
object HdRezkaLoginClient {
    /**
     * Checks the shape of the standard DLE authentication cookie pair only.
     * This does not prove that the remote server still accepts the session.
     */
    fun hasAuthenticatedCookie(cookieHeader: String): Boolean {
        if (cookieHeader.isBlank() || cookieHeader.length > 8_192 ||
            cookieHeader.any { it == '\r' || it == '\n' }
        ) return false
        val values = cookieHeader.split(';').mapNotNull { part ->
            val pair = part.trim().split('=', limit = 2)
            pair.takeIf { it.size == 2 && it[0].isNotBlank() }
                ?.let { it[0].trim().lowercase() to it[1].trim() }
        }.toMap()
        val userId = values["dle_user_id"].orEmpty()
        val password = values["dle_password"].orEmpty()
        return userId.isNotBlank() && userId != "0" && password.isNotBlank()
    }

    private const val MAX_RESPONSE_BYTES = 512 * 1024
    private const val MAX_RESPONSE_PREVIEW_BYTES = 64 * 1024
    private const val MAX_REDIRECTS = 6
    private val REDIRECT_CODES = setOf(301, 302, 303, 307, 308)

    fun validateMirror(value: String): String {
        val supplied = value.trim()
        require(supplied.isNotBlank()) { "Укажите адрес источника HDRezka" }
        val clean = supplied.trimEnd('/') + "/"
        val uri = runCatching { URI(clean) }
            .getOrElse { throw IllegalArgumentException("Некорректный адрес зеркала HDRezka", it) }
        require(uri.scheme.equals("https", true)) { "Зеркало должно использовать HTTPS" }
        require(!uri.host.isNullOrBlank() && uri.rawUserInfo == null) {
            "Укажите HTTPS-домен зеркала без логина и пароля в URL"
        }
        val host = uri.host.lowercase().removePrefix("www.")
        // rezkify.com is a user-reported alternate mirror; keep it as an exact
        // allowlisted host rather than trusting arbitrary redirect domains.
        val isRezkaMirror = host == "rezkify.com" ||
            host.startsWith("hdrezka.") || host.startsWith("hdrezka-") ||
            host.startsWith("rezka.") || host.startsWith("rezka-") ||
            host.startsWith("standby-rezka.")
        require(isRezkaMirror) {
            "Адрес должен относиться к зеркалу HDRezka"
        }
        require(uri.rawQuery.isNullOrBlank() && uri.rawFragment.isNullOrBlank() &&
            (uri.rawPath.isNullOrBlank() || uri.rawPath == "/")
        ) { "Укажите только домен зеркала, без пути и параметров" }
        return clean.trimEnd('/')
    }

    fun login(mirror: String, username: String, password: String): HdRezkaLoginResult {
        require(username.isNotBlank()) { "Введите логин или email HDRezka" }
        require(password.isNotBlank()) { "Введите пароль HDRezka" }

        val initialMirror = validateMirror(mirror)
        val cookies = CookieManager(null, CookiePolicy.ACCEPT_ALL)
        // The landing page is only needed for redirects and Set-Cookie headers.
        // Avoid buffering its often-large HTML during login.
        val bootstrap = requestFollowingGetRedirects("$initialMirror/", cookies, captureBody = false)
        val activeBase = validateMirror(originOf(bootstrap.finalUrl))

        val form = listOf(
            "login_name" to username,
            "login_password" to password,
            "login_not_save" to "0",
            "login" to "submit"
        ).joinToString("&") { "${encode(it.first)}=${encode(it.second)}" }

        val response = requestFollowingLoginRedirects(
            startUrl = "$activeBase/ajax/login/?t=${System.currentTimeMillis()}",
            body = form,
            cookies = cookies,
            referer = "$activeBase/"
        )
        val confirmedBase = validateMirror(originOf(response.finalUrl))
        if (response.status == 403 || containsChallenge(response.body)) {
            throw IOException(
                "HDRezka показала защитную проверку. Jacket не обходит CAPTCHA или Cloudflare; " +
                    "войдите через обычный браузер и вставьте свою Cookie-сессию."
            )
        }
        if (response.status !in 200..299) {
            throw IOException("HDRezka вернула HTTP ${response.status}")
        }

        val cookieHeader = cookies.get(URI("$confirmedBase/"), emptyMap())
            .entries.firstOrNull { it.key.equals("Cookie", true) }
            ?.value.orEmpty().joinToString("; ")
        if (!hasAuthenticatedCookie(cookieHeader)) {
            throw IOException("HDRezka не подтвердила вход: сервер не выдал dle_user_id и dle_password.")
        }
        return HdRezkaLoginResult(confirmedBase, cookieHeader)
    }

    /** Checks a mirror without sending account credentials. */
    fun probeMirror(mirror: String): String {
        val initialMirror = validateMirror(mirror)
        val cookies = CookieManager(null, CookiePolicy.ACCEPT_ALL)
        val response = requestFollowingGetRedirects(
            "$initialMirror/",
            cookies,
            captureBody = true,
            previewOnly = true
        )
        if (containsChallenge(response.body)) {
            throw IOException("Зеркало доступно, но требует браузерную проверку CAPTCHA/Cloudflare.")
        }
        return validateMirror(originOf(response.finalUrl))
    }

    /** Converts network failures into useful diagnostics without exposing cookies or headers. */
    fun userFriendlyError(error: Throwable): String {
        val chain = generateSequence(error) { it.cause }.take(8).toList()
        return when {
            chain.any { it is javax.net.ssl.SSLException } ->
                "Ошибка HTTPS-сертификата HDRezka. Сертификаты не обходятся; проверьте доступность разрешённого источника и правильность домена."
            chain.any { it is java.net.UnknownHostException } ->
                "Не удалось найти домен HDRezka. Проверьте зеркало и DNS/доступ к сайту."
            chain.any { it is java.net.SocketTimeoutException } ->
                "HDRezka не ответила вовремя. Зеркало перегружено или недоступно из вашей сети."
            chain.any { it is java.net.ConnectException } ->
                "Не удалось подключиться к HDRezka. Проверьте доступность зеркала или сеть."
            else -> error.message?.replace(Regex("[\\r\\n\\t]+"), " ")?.take(240)
                ?.ifBlank { "Не удалось подключиться к HDRezka." } ?: "Не удалось подключиться к HDRezka."
        }
    }

    internal fun loginRedirectMethod(status: Int): String? = when (status) {
        301, 302, 303 -> "GET"
        307, 308 -> null
        else -> ""
    }

    private data class HttpResult(
        val status: Int,
        val finalUrl: String,
        val body: String,
        val location: String?
    )

    private fun requestFollowingLoginRedirects(
        startUrl: String,
        body: String,
        cookies: CookieManager,
        referer: String
    ): HttpResult {
        var currentUrl = startUrl
        var method = "POST"
        var currentBody: String? = body
        var currentReferer = referer
        repeat(MAX_REDIRECTS + 1) {
            // The response body is inspected only for anti-bot markers. Do not
            // download hundreds of kilobytes of a login page just to classify it.
            val response = request(
                currentUrl,
                method,
                currentBody,
                cookies,
                currentReferer,
                captureBody = true,
                previewOnly = true
            )
            if (response.status !in REDIRECT_CODES) return response

            val location = response.location
                ?: throw IOException("HDRezka перенаправила вход без адреса (HTTP ${response.status})")
            val nextUrl = resolveRedirect(currentUrl, location)
            val nextMethod = loginRedirectMethod(response.status)
                ?: method.takeIf { sameOrigin(currentUrl, nextUrl) }
                ?: throw IOException("HDRezka перенаправила вход на другой домен; повторная отправка пароля заблокирована.")
            if (nextMethod.isEmpty()) {
                throw IOException("HDRezka вернула неожиданный код перенаправления")
            }
            if (nextMethod == "GET") currentBody = null
            currentUrl = nextUrl
            method = nextMethod
            currentReferer = originOf(currentUrl) + "/"
        }
        throw IOException("Слишком много перенаправлений при входе в HDRezka")
    }

    private fun sameOrigin(first: String, second: String): Boolean = runCatching {
        val a = URI(first)
        val b = URI(second)
        a.scheme.equals(b.scheme, true) &&
            a.host.equals(b.host, true) &&
            effectivePort(a) == effectivePort(b)
    }.getOrDefault(false)

    private fun effectivePort(uri: URI): Int =
        if (uri.port >= 0) uri.port else 443

    internal fun containsBrowserChallenge(body: String): Boolean =
        body.contains("cf-chl", true) ||
            body.contains("Just a moment", true) ||
            body.contains("challenge-platform", true) ||
            (body.contains("anubis", true) &&
                (body.contains("Доступ запрещён", true) || body.contains("Access denied", true)))

    private fun containsChallenge(body: String): Boolean = containsBrowserChallenge(body)

    private fun requestFollowingGetRedirects(
        startUrl: String,
        cookies: CookieManager,
        captureBody: Boolean = true,
        previewOnly: Boolean = false
    ): HttpResult {
        var currentUrl = startUrl
        repeat(MAX_REDIRECTS + 1) {
            val response = request(
                currentUrl, "GET", null, cookies, currentUrl,
                captureBody = captureBody, previewOnly = previewOnly
            )
            if (response.status in setOf(301, 302, 303, 307, 308)) {
                val location = response.location
                    ?: throw IOException("HDRezka вернула перенаправление без адреса")
                currentUrl = resolveRedirect(currentUrl, location)
            } else {
                if (response.status == 403 || containsChallenge(response.body)) {
                    throw IOException("HDRezka требует браузерную проверку. Автоматический обход не выполняется.")
                }
                if (response.status !in 200..299) {
                    throw IOException("Не удалось определить рабочее зеркало HDRezka: HTTP ${response.status}")
                }
                return response
            }
        }
        throw IOException("Слишком много перенаправлений при поиске зеркала HDRezka")
    }

    private fun request(
        url: String,
        method: String,
        body: String?,
        cookies: CookieManager,
        referer: String,
        captureBody: Boolean = true,
        previewOnly: Boolean = false
    ): HttpResult {
        val uri = URI(url)
        validateMirror(originOf(url))
        val connection = (URL(url).openConnection() as HttpURLConnection).apply {
            requestMethod = method
            connectTimeout = 12_000
            readTimeout = 15_000
            instanceFollowRedirects = false
            setRequestProperty("Accept", "application/json, text/plain, */*")
            setRequestProperty("Cache-Control", "no-cache")
            setRequestProperty("Accept-Language", "ru-RU,ru;q=0.9,en;q=0.8")
            setRequestProperty("User-Agent", "Jacket-Android/2.6")
            setRequestProperty("Referer", referer)
            setRequestProperty("X-Requested-With", "XMLHttpRequest")
            setRequestProperty("Origin", originOf(url))
            cookies.get(uri, emptyMap()).forEach { (name, values) ->
                if (name.equals("Cookie", true)) setRequestProperty(name, values.joinToString("; "))
            }
            if (body != null) {
                doOutput = true
                setRequestProperty("Content-Type", "application/x-www-form-urlencoded; charset=UTF-8")
            }
        }
        try {
            if (body != null) {
                connection.outputStream.use { it.write(body.toByteArray(Charsets.UTF_8)) }
            }
            val status = connection.responseCode
            val responseHeaders = connection.headerFields.entries
                .filter { it.key != null }
                .associate { it.key!! to it.value.orEmpty() }
            cookies.put(uri, responseHeaders)
            // Redirect and mirror-bootstrap bodies are not needed to resolve the
            // active host. Skipping them avoids buffering the full HDRezka homepage.
            val shouldReadBody = captureBody && status !in REDIRECT_CODES
            val stream = if (status in 200..299) connection.inputStream else connection.errorStream
            val bytes = if (!shouldReadBody) {
                ByteArray(0)
            } else {
                stream?.use { input ->
                    if (previewOnly) {
                        readResponsePreview(input, MAX_RESPONSE_PREVIEW_BYTES)
                    } else {
                        readResponseBody(input, MAX_RESPONSE_BYTES)
                    }
                } ?: ByteArray(0)
            }
            return HttpResult(
                status = status,
                finalUrl = connection.url.toString(),
                body = bytes.toString(Charsets.UTF_8),
                location = connection.getHeaderField("Location")
            )
        } finally {
            connection.disconnect()
        }
    }

    internal fun readResponsePreview(input: java.io.InputStream, maxBytes: Int): ByteArray {
        require(maxBytes > 0)
        val output = ByteArrayOutputStream()
        val buffer = ByteArray(8_192)
        while (output.size() < maxBytes) {
            val count = input.read(buffer, 0, minOf(buffer.size, maxBytes - output.size()))
            if (count < 0) break
            if (count > 0) output.write(buffer, 0, count)
        }
        return output.toByteArray()
    }

    private fun readResponseBody(input: java.io.InputStream, maxBytes: Int): ByteArray {
        input.use { source ->
            val output = ByteArrayOutputStream()
            val buffer = ByteArray(8_192)
            while (true) {
                val count = source.read(buffer)
                if (count < 0) break
                if (output.size() + count > maxBytes) throw IOException("Ответ HDRezka слишком большой")
                output.write(buffer, 0, count)
            }
            return output.toByteArray()
        }
    }

    private fun resolveRedirect(baseUrl: String, location: String): String {
        val resolved = URL(URL(baseUrl), location).toString()
        validateMirror(originOf(resolved))
        return resolved
    }

    private fun originOf(value: String): String {
        val uri = URI(value)
        return "${uri.scheme}://${uri.rawAuthority}"
    }

    private fun encode(value: String): String =
        URLEncoder.encode(value, Charsets.UTF_8.name()).replace("+", "%20")
}

package app.jacket.mobile.data

import java.net.URI

/**
 * Sanitizes diagnostics before they reach toasts, status labels or logs.
 * Credentials configured for a provider are redacted even if they occur in
 * path segments or an unusual query parameter name.
 */
internal object IndexerErrorSanitizer {
    private val sensitiveParameter = Regex(
        "(?i)(apikey|api[_-]?key|jackett[_-]?apikey|access[_-]?token|token|password|passwd|pwd|secret|cookie|authorization|auth)=([^&\\s#]+)"
    )
    private val sensitiveHeader = Regex("(?i)\\b(authorization|cookie|x-api-key)\\s*:\\s*[^\\r\\n]*")
    private val basicCredentials = Regex("(?i)\\bBasic\\s+[A-Za-z0-9+/=]+")
    private val bearerCredentials = Regex("(?i)\\bBearer\\s+[A-Za-z0-9._~+/-]+=*")
    private val url = Regex("""(?i)https?://[^\s<>"']+""")
    private val whitespace = Regex("[\\r\\n\\t]+")

    fun sanitize(error: Throwable, configuredSecrets: Collection<String> = emptyList()): String {
        val messages = generateSequence(error) { it.cause }
            .take(8)
            .mapNotNull { it.message }
            .toList()
        return sanitize(messages.joinToString(": ").ifBlank { error.javaClass.simpleName }, configuredSecrets)
    }

    fun sanitize(rawMessage: String, configuredSecrets: Collection<String> = emptyList()): String {
        var safe = rawMessage
        configuredSecrets.asSequence()
            .filter { it.isNotBlank() && it.length >= 3 }
            .distinct()
            .sortedByDescending(String::length)
            .forEach { secret -> safe = safe.replace(secret, "[redacted]") }

        safe = sensitiveParameter.replace(safe) { "${it.groupValues[1]}=[redacted]" }
        safe = sensitiveHeader.replace(safe) { "${it.groupValues[1]}: [redacted]" }
        safe = basicCredentials.replace(safe, "Basic [redacted]")
        safe = bearerCredentials.replace(safe, "Bearer [redacted]")
        safe = url.replace(safe) { match ->
            val candidate = match.value.trimEnd('.', ',', ')', ']', ';')
            val suffix = match.value.substring(candidate.length)
            val authority = runCatching {
                // Parse only scheme + authority. The path may already contain
                // [redacted] markers, which are not legal URI path characters.
                val parts = Regex("(?i)^(https?)://([^/?#]+)").find(candidate)
                    ?: return@runCatching "[URL]"
                val scheme = parts.groupValues[1].lowercase()
                val rawAuthority = parts.groupValues[2].substringAfterLast('@')
                val uri = URI("$scheme://$rawAuthority")
                val host = uri.host ?: return@runCatching "[URL]"
                val port = if (uri.port >= 0) ":${uri.port}" else ""
                val queryMarker = if (candidate.contains('?')) "/?[redacted]" else ""
                "$scheme://$host$port$queryMarker"
            }.getOrDefault("[URL]")
            authority + suffix
        }
        return safe.replace(whitespace, " ").trim().take(180)
    }
}

package app.jacket.mobile.data

import org.xmlpull.v1.XmlPullParserFactory

/**
 * Pluggable direct indexer federation. Supports user-configured RSS/Atom and Torznab/Newznab
 * endpoints without running a separate Jackett service. Credentials are supplied only over HTTPS.
 */
class IndexerRegistry(
    private val catalog: MediaCatalogClient = MediaCatalogClient()
) {
    private data class SearchTask(
        val indexerId: String,
        val indexerName: String,
        val config: IndexerConfig?,
        val future: Future<Result<List<SourceResult>>>
    )

    fun search(
        query: String,
        customIndexers: List<IndexerConfig>,
        includeArchive: Boolean = true
    ): List<SourceResult> = searchDetailed(query, customIndexers, includeArchive).results

    /** Runs no more than four source requests concurrently; one failed provider never cancels peers. */
    fun searchDetailed(
        query: String,
        customIndexers: List<IndexerConfig>,
        includeArchive: Boolean = true
    ): IndexerSearchOutcome {
        val active = customIndexers.asSequence()
            .filter { it.enabled }
            .take(MAX_INDEXERS)
            .toList()
        val executor = Executors.newFixedThreadPool(MAX_PARALLEL_REQUESTS)
        try {
            val tasks = buildList {
                if (includeArchive) {
                    add(
                        SearchTask(
                            indexerId = "archive",
                            indexerName = "Internet Archive",
                            config = null,
                            future = executor.submit(Callable {
                                runCatching { catalog.archiveSources(query) }
                            })
                        )
                    )
                }
                active.forEach { config ->
                    add(
                        SearchTask(
                            indexerId = config.id,
                            indexerName = config.name,
                            config = config,
                            future = executor.submit(Callable {
                                runCatching { searchFeed(config, query) }
                            })
                        )
                    )
                }
            }

            val results = ArrayList<SourceResult>()
            val failures = ArrayList<IndexerFailure>()
            tasks.forEach { task ->
                try {
                    val result = task.future.get()
                    result.onSuccess(results::addAll).onFailure { error ->
                        failures += IndexerFailure(
                            indexerId = task.indexerId,
                            indexerName = task.indexerName,
                            message = safeError(error, task.config)
                        )
                    }
                } catch (error: Exception) {
                    failures += IndexerFailure(
                        task.indexerId,
                        task.indexerName,
                        safeError(error, task.config)
                    )
                }
            }

            return IndexerSearchOutcome(orderResults(results), failures)
        } finally {
            executor.shutdownNow()
            runCatching { executor.awaitTermination(250, TimeUnit.MILLISECONDS) }
        }
    }

    fun searchOne(config: IndexerConfig, query: String): List<SourceResult> {
        require(config.enabled) { "Индексатор отключён" }
        require(query.isNotBlank()) { "Введите поисковый запрос" }
        return try {
            searchFeed(config, query.trim())
        } catch (error: Exception) {
            throw IOException(safeError(error, config))
        }
    }

    /** A valid empty response still means that the authenticated indexer is reachable. */
    fun test(config: IndexerConfig): Int {
        val probeConfig = if (config.protocol == IndexerProtocol.JACKETT) {
            val parsed = JackettUrl.parseTemplate(config.searchUrlTemplate)
                ?: throw IOException("Некорректный URL Jackett")
            config.copy(searchUrlTemplate = JackettUrl.capabilitiesTemplate(parsed.baseUrl, parsed.indexer))
        } else config
        return try {
            searchFeed(probeConfig, "jacket-connectivity-test").size
        } catch (error: Exception) {
            throw IOException(safeError(error, config))
        }
    }

    fun testAll(configs: List<IndexerConfig>): List<IndexerFailure> {
        val executor = Executors.newFixedThreadPool(MAX_PARALLEL_REQUESTS)
        try {
            val futures = configs.filter { it.enabled }.take(MAX_INDEXERS).map { config ->
                config to executor.submit(Callable { runCatching { test(config) } })
            }
            return futures.mapNotNull { (config, future) ->

                }
                result.exceptionOrNull()?.let { IndexerFailure(config.id, config.name, safeError(it, config)) }
            }
        } finally {
            executor.shutdownNow()
            runCatching { executor.awaitTermination(250, TimeUnit.MILLISECONDS) }
        }
    }

    internal fun parseFeedXml(xml: String, config: IndexerConfig): List<SourceResult> =

    internal fun parseFeedXml(xml: String, config: IndexerConfig, parser: XmlPullParser): List<SourceResult> =

    internal fun orderResults(results: List<SourceResult>): List<SourceResult> =
        results
            .distinctBy { it.magnetUri ?: it.downloadUrl ?: it.streamUrl ?: it.id }
            .sortedWith(compareByDescending<SourceResult> { it.seeders ?: -1 }.thenBy { it.title.lowercase() })
            .take(MAX_TOTAL_RESULTS)

    private fun searchFeed(config: IndexerConfig, query: String): List<SourceResult> {
        val requestUrl = buildRequestUrl(config, query)
        val uri = runCatching { java.net.URI(requestUrl) }.getOrElse { throw IOException("Некорректный URL индексатора", it) }
        if (!LocalNetwork.isAllowedUrl(requestUrl)) {
            throw IOException("Источник «${config.name}» должен использовать HTTPS или локальный HTTP без логина в URL")
        }

        val connection = (URL(requestUrl).openConnection() as HttpURLConnection).apply {
            requestMethod = "GET"
            connectTimeout = CONNECT_TIMEOUT_MS
            readTimeout = READ_TIMEOUT_MS
            instanceFollowRedirects = false
            setRequestProperty("Accept", "application/rss+xml, application/atom+xml, application/xml, text/xml")
            setRequestProperty("User-Agent", USER_AGENT)
            if (config.username.isNotBlank() || config.password.isNotBlank()) {
                val credentials = "${config.username}:${config.password}"
                val encoded = java.util.Base64.getEncoder().encodeToString(credentials.toByteArray(Charsets.UTF_8))
                setRequestProperty("Authorization", "Basic $encoded")
            }
            if (config.cookie.isNotBlank()) setRequestProperty("Cookie", config.cookie.take(4096))
            if (config.apiKey.isNotBlank()) setRequestProperty("X-Api-Key", config.apiKey.take(512))
        }
        val body = try {
            val status = connection.responseCode
            if (status !in 200..299) throw IOException("HTTP $status от ${config.name}")
            connection.inputStream.use { input ->
                val output = ByteArrayOutputStream()
                val buffer = ByteArray(8192)
                var total = 0
                while (true) {
                    val count = input.read(buffer)
                    if (count < 0) break
                    total += count
                    if (total > MAX_FEED_BYTES) throw IOException("Ответ ${config.name} слишком большой")
                    output.write(buffer, 0, count)
                }
                output.toByteArray()
            }
        } finally {
            connection.disconnect()
        }
        return parseFeed(body, config)
    }

    private fun buildRequestUrl(config: IndexerConfig, query: String): String {
        val template = config.searchUrlTemplate
        val substituted = template
            .replace("{query}", urlEncode(query))
            .replace("{apikey}", urlEncode(config.apiKey))
        val uri = runCatching { java.net.URI(substituted) }
            .getOrElse { throw IOException("Некорректный URL индексатора", it) }
        if (!LocalNetwork.isAllowedUrl(substituted)) {
            throw IOException("Индексатор должен использовать HTTPS или локальный HTTP без логина в URL")
        }

        val queryParts = uri.rawQuery.orEmpty().split('&').filter(String::isNotBlank).toMutableList()
        val existingNames = queryParts.mapTo(HashSet()) { part ->
            runCatching { java.net.URLDecoder.decode(part.substringBefore('='), Charsets.UTF_8.name()) }
                .getOrDefault(part.substringBefore('='))
                .lowercase()
        }
        fun appendIfMissing(key: String, value: String?) {
            if (!value.isNullOrBlank() && key.lowercase() !in existingNames) {
                queryParts += "${urlEncode(key)}=${urlEncode(value)}"
                existingNames += key.lowercase()
            }
        }

        appendIfMissing("apikey", config.apiKey.takeIf { it.isNotBlank() && "{apikey}" !in template })
        if (config.protocol == IndexerProtocol.TORZNAB || config.protocol == IndexerProtocol.JACKETT) {
            appendIfMissing("t", "search")
            appendIfMissing("cat", config.categories)
            appendIfMissing("tag", config.tags)
            appendIfMissing("sort", config.sortBy)
            appendIfMissing("order", config.sortOrder)
            if (config.freeleechOnly) appendIfMissing("freeleech", "1")
        }
        return buildString {
            append(uri.scheme).append("://").append(uri.rawAuthority)
            if (!uri.rawPath.isNullOrEmpty()) append(uri.rawPath)
            if (queryParts.isNotEmpty()) append('?').append(queryParts.joinToString("&"))
            if (!uri.rawFragment.isNullOrEmpty()) append('#').append(uri.rawFragment)
        }
    }

    private fun urlEncode(value: String): String =
        java.net.URLEncoder.encode(value, Charsets.UTF_8.name()).replace("+", "%20")

    private fun newXmlParser(): XmlPullParser =
        XmlPullParserFactory.newInstance().newPullParser()

    private fun parseFeed(xml: ByteArray, config: IndexerConfig): List<SourceResult> =
        parseFeed(xml, config, newXmlParser())

    private fun parseFeed(xml: ByteArray, config: IndexerConfig, parser: XmlPullParser): List<SourceResult> {
        parser.setFeature(XmlPullParser.FEATURE_PROCESS_NAMESPACES, false)
        runCatching { parser.setFeature(XmlPullParser.FEATURE_PROCESS_DOCDECL, false) }
        parser.setInput(xml.inputStream(), "UTF-8")

        val result = mutableListOf<SourceResult>()
        var inEntry = false
        var title = ""
        var pageUrl: String? = null
        var detailsUrl: String? = null
        var magnet: String? = null
        var torrentUrl: String? = null
        var streamUrl: String? = null
        var tracker: String? = null
        var size: Long? = null
        var seeders: Int? = null
        var leechers: Int? = null
        var peers: Int? = null
        var category: String? = null
        var publishedDate: String? = null

        fun reset() {
            title = ""
            pageUrl = null
            detailsUrl = null
            magnet = null
            torrentUrl = null
            streamUrl = null
            tracker = null
            size = null
            seeders = null
            leechers = null
            peers = null
            category = null
            publishedDate = null
        }

        var event = parser.eventType
        while (event != XmlPullParser.END_DOCUMENT && result.size < MAX_FEED_RESULTS) {
            when (event) {
                XmlPullParser.START_TAG -> {
                    val name = parser.name.substringAfter(':').lowercase()
                    when (name) {
                        "error" -> if (!inEntry) {
                            val code = parser.getAttributeValue(null, "code").orEmpty()
                            val description = parser.getAttributeValue(null, "description").orEmpty()
                            throw IOException(
                                config.name + ": " + description.ifBlank { "ошибка индексатора" } +
                                    if (code.isBlank()) "" else " (код " + code + ")"
                            )
                        }
                        "item", "entry" -> {
                            inEntry = true
                            reset()
                        }
                        "title" -> if (inEntry) title = parser.nextText().trim()
                        "jackettindexer", "prowlarrindexer" -> if (inEntry) {
                            tracker = parser.nextText().trim().takeIf(String::isNotBlank)
                        }
                        "comments" -> if (inEntry) {
                            detailsUrl = parser.nextText().trim().takeIf(String::isNotBlank)
                        }
                        "size" -> if (inEntry) {
                            size = parser.nextText().trim().toLongOrNull()?.takeIf { it >= 0L }
                        }
                        "pubdate", "published", "publishedat", "date" -> if (inEntry) {
                            publishedDate = parser.nextText().trim().takeIf(String::isNotBlank)?.take(120)
                        }
                        "link" -> if (inEntry) {
                            val href = parser.getAttributeValue(null, "href")
                            val rel = parser.getAttributeValue(null, "rel")
                            val value = href?.takeIf(String::isNotBlank) ?: parser.nextText().trim()
                            val contentType = parser.getAttributeValue(null, "type").orEmpty()
                            when {
                                value.startsWith("magnet:", true) -> magnet = value
                                rel.equals("enclosure", true) &&
                                    (value.endsWith(".torrent", true) || contentType.contains("bittorrent", true)) ->
                                    torrentUrl = value
                                isPlayableVideoUrl(value, contentType) -> streamUrl = value
                                value.isNotBlank() && pageUrl == null -> pageUrl = value
                            }
                        }
                        "enclosure" -> if (inEntry) {
                            val value = parser.getAttributeValue(null, "url").orEmpty()
                            val type = parser.getAttributeValue(null, "type").orEmpty()
                            when {
                                value.startsWith("magnet:", true) -> magnet = value
                                value.endsWith(".torrent", true) || type.contains("bittorrent", true) -> torrentUrl = value
                                isPlayableVideoUrl(value, type) -> streamUrl = value
                                value.startsWith("https://") && pageUrl == null -> pageUrl = value
                            }
                        }
                        "content" -> if (inEntry) {
                            val value = parser.getAttributeValue(null, "url").orEmpty()
                            val type = parser.getAttributeValue(null, "type").orEmpty()
                            val medium = parser.getAttributeValue(null, "medium").orEmpty()
                            if (isPlayableVideoUrl(value, type) || medium.equals("video", ignoreCase = true)) {
                                if (isHttps(value)) streamUrl = value
                            }
                            val fileSize = parser.getAttributeValue(null, "fileSize")?.toLongOrNull()?.takeIf { it >= 0L }
                            if (size == null) size = fileSize
                        }
                        "guid", "id" -> if (inEntry && pageUrl == null) pageUrl = parser.nextText().trim()
                        "category" -> if (inEntry) {
                            val value = parser.getAttributeValue(null, "id")
                                ?: parser.getAttributeValue(null, "term")
                                ?: parser.nextText()
                            category = value.trim().takeIf(String::isNotBlank)
                        }
                        "attr" -> if (inEntry) {
                            val attr = parser.getAttributeValue(null, "name")?.lowercase().orEmpty()
                            val value = parser.getAttributeValue(null, "value")
                            when (attr) {
                                "magneturl" -> if (!value.isNullOrBlank()) magnet = value
                                "seeders" -> seeders = value?.toIntOrNull()?.takeIf { it >= 0 }
                                "peers" -> peers = value?.toIntOrNull()?.takeIf { it >= 0 }
                                "leechers" -> leechers = value?.toIntOrNull()?.takeIf { it >= 0 }
                                "size", "length" -> {
                                    val parsed = value?.toLongOrNull()?.takeIf { it >= 0L }
                                    if (parsed != null) size = parsed
                                }
                                "category", "categoryid" -> if (!value.isNullOrBlank()) category = value
                                "pubdate", "publishdate", "published" -> if (!value.isNullOrBlank()) publishedDate = value.take(120)
                            }
                        }
                    }
                }
                XmlPullParser.DOCDECL -> throw IOException("XML document type declarations are not supported")
                XmlPullParser.END_TAG -> {
                    val name = parser.name.substringAfter(':').lowercase()
                    if (inEntry && name in setOf("item", "entry")) {
                        val safeMagnet = magnet?.takeIf { it.startsWith("magnet:", true) }
                        val safeTorrent = torrentUrl?.takeIf(LocalNetwork::isAllowedUrl)
                        val safeStream = streamUrl?.takeIf(LocalNetwork::isAllowedUrl)
                        val safePage = (detailsUrl ?: pageUrl)?.takeIf(LocalNetwork::isAllowedUrl)
                        if (title.isNotBlank() &&
                            (safeMagnet != null || safeTorrent != null || safeStream != null || safePage != null)
                        ) {
                            result += SourceResult(
                                id = "${config.id}:${result.size}:${title.hashCode()}",
                                title = title,
                                providerName = config.name,
                                magnetUri = safeMagnet,
                                downloadUrl = safeTorrent,
                                streamUrl = safeStream,
                                sizeBytes = size,
                                seeders = seeders,
                                leechers = leechers ?: peers?.let { (it - (seeders ?: 0)).coerceAtLeast(0) },
                                pageUrl = safePage,
                                category = category,
                                indexerId = config.id,
                                tracker = tracker,
                                publishedDate = publishedDate
                            )
                        }
                        inEntry = false
                    }
                }
            }
            event = parser.next()
        }
        return result
    }

    private fun isPlayableVideoUrl(value: String, contentType: String): Boolean {
        if (!LocalNetwork.isAllowedUrl(value)) return false
        val mime = contentType.substringBefore(';').trim().lowercase()
        if (mime.startsWith("video/") || mime in PLAYLIST_MIME_TYPES) return true
        val path = runCatching { java.net.URI(value).rawPath.orEmpty().lowercase() }.getOrDefault("")
        return VIDEO_EXTENSIONS.any { extension -> path.endsWith(extension) }
    }

    private fun isHttps(value: String): Boolean = runCatching {
        val uri = java.net.URI(value)
        uri.scheme.equals("https", true) && !uri.host.isNullOrBlank() && uri.rawUserInfo == null
    }.getOrDefault(false)

    private fun safeError(error: Throwable, config: IndexerConfig? = null): String =
        IndexerErrorSanitizer.sanitize(
            error,
            listOfNotNull(config?.apiKey, config?.cookie, config?.username, config?.password)
        )

    private companion object {
        const val MAX_INDEXERS = 100
        const val MAX_PARALLEL_REQUESTS = 4
        const val MAX_TOTAL_RESULTS = 200
        const val MAX_FEED_RESULTS = 100
        const val MAX_FEED_BYTES = 4 * 1024 * 1024
        val PLAYLIST_MIME_TYPES = setOf(
            "application/vnd.apple.mpegurl",
            "application/x-mpegurl",
            "application/dash+xml"
        )
        val VIDEO_EXTENSIONS = setOf(
            ".m3u8", ".mpd", ".mp4", ".m4v", ".mov", ".webm", ".mkv", ".ogv"
        )
        const val CONNECT_TIMEOUT_MS = 10_000
        const val READ_TIMEOUT_MS = 25_000
        const val USER_AGENT = "JacketAndroid/2.1 (direct indexer federation)"
    }

/**
 * Jackett's native REST administration API.
 *
 * The public catalogue and per-indexer setup endpoints are different from Torznab search:
 * - GET /api/v2.0/indexers returns the public/private/configured/capabilities catalogue.
 * - GET /api/v2.0/indexers/{id}/config returns dynamic setup controls.
 * - POST /api/v2.0/indexers/{id}/config saves those controls.
 *
 * Management endpoints use the user's authenticated Jackett dashboard session cookie,
 * stored in IndexerConfig.cookie (encrypted locally). The API key remains for Torznab search.
 */
object JackettIndexerClient {
    private const val MAX_RESPONSE_BYTES = 2 * 1024 * 1024
    private const val MAX_CONFIG_FIELDS = 120
    private const val MAX_CONFIG_BODY_BYTES = 128 * 1024
    private const val CONNECT_TIMEOUT_MS = 8_000
    private const val READ_TIMEOUT_MS = 12_000
    private const val USER_AGENT = "JacketAndroid/2.6 (Jackett native indexer manager)"
    private val INDEXER_ID_PATTERN = Regex("[a-zA-Z0-9][a-zA-Z0-9._:-]{0,99}")

    fun fetch(config: IndexerConfig): List<JackettIndexerEntry> {
        validateJackettConfig(config)
        val url = buildIndexersUrl(baseUrl(config))
        val body = execute(config, url, "GET").toString(Charsets.UTF_8)
        val entries = parseIndexersJson(body, listOf(config.apiKey, config.cookie, config.username, config.password))
        if (entries.isEmpty()) throw IOException("Jackett вернул пустой каталог индексаторов")
        return entries
    }

    /** Reads the editable controls for one indexer; dashboard Cookie is required when auth is enabled. */
    fun fetchIndexerConfig(config: IndexerConfig, indexerId: String): List<JackettConfigField> {
        validateJackettConfig(config)
        val url = buildIndexerConfigUrl(baseUrl(config), indexerId)
        val body = execute(config, url, "GET").toString(Charsets.UTF_8)
        return parseIndexerConfig(body)
    }

    /** Runs Jackett's own tracker test endpoint and lets it update last_error. */
    fun testIndexer(config: IndexerConfig, indexerId: String) {
        validateJackettConfig(config)
        execute(config, buildIndexerTestUrl(baseUrl(config), indexerId), "POST")
    }

    /** Saves the dynamic controls and lets Jackett test the indexer when its config requires it. */
    fun updateIndexerConfig(
        config: IndexerConfig,
        indexerId: String,
        fields: List<JackettConfigField>
    ) {
        validateJackettConfig(config)
        require(fields.size <= MAX_CONFIG_FIELDS) { "Слишком много настроек индексатора" }
        val url = buildIndexerConfigUrl(baseUrl(config), indexerId)
        val body = buildConfigPayload(fields).toString()
        require(body.toByteArray(Charsets.UTF_8).size <= MAX_CONFIG_BODY_BYTES) {
            "Данные настройки индексатора слишком большие"
        }
        execute(config, url, "POST", body.toByteArray(Charsets.UTF_8))
    }

    /** Creates the REST catalogue endpoint used by Jackett's own dashboard. */
    internal fun buildIndexersUrl(baseUrl: String): String {
        val base = JackettUrl.normalizeBase(baseUrl)
            ?: throw IllegalArgumentException("Некорректный адрес сервера Jackett")
        return "$base/api/v2.0/indexers"
    }

    internal fun buildIndexerConfigUrl(baseUrl: String, indexerId: String): String {
        require(INDEXER_ID_PATTERN.matches(indexerId)) {
            "Jackett вернул некорректный идентификатор индексатора"
        }
        return buildIndexersUrl(baseUrl) + "/" +
            URLEncoder.encode(indexerId, Charsets.UTF_8.name()) + "/config"

    internal fun buildIndexerTestUrl(baseUrl: String, indexerId: String): String {
        require(INDEXER_ID_PATTERN.matches(indexerId)) {

    internal fun parseIndexersJson(
        json: String,
        configuredSecrets: Collection<String> = emptyList()
    ): List<JackettIndexerEntry> {
        require(json.length <= MAX_RESPONSE_BYTES) { "Ответ каталога Jackett слишком большой" }
        val array = runCatching { JSONArray(json) }
            .getOrElse { throw IOException("Jackett вернул некорректный JSON каталога", it) }
        val entries = LinkedHashMap<String, JackettIndexerEntry>()
        for (index in 0 until minOf(array.length(), 1_000)) {
            val item = array.optJSONObject(index) ?: continue
            val id = item.optString("id").trim()
            if (!INDEXER_ID_PATTERN.matches(id)) continue
            val capabilities = item.optJSONArray("caps")
            val categoryIds = ArrayList<String>()
            val categoryNames = ArrayList<String>()
            if (capabilities != null) {
                for (capIndex in 0 until minOf(capabilities.length(), 500)) {
                    val capability = capabilities.optJSONObject(capIndex) ?: continue
                    val categoryId = capability.optString("ID").takeIf(String::isNotBlank)
                    val categoryName = capability.optString("Name").trim().takeIf(String::isNotBlank)
                    if (categoryId != null) categoryIds += categoryId
                    if (categoryName != null) categoryNames += categoryName
                }
            }
            val alternateLinks = item.optJSONArray("alternativesitelinks")?.toStringList().orEmpty()
                .filter(LocalNetwork::isAllowedUrl).take(20)
            val siteLink = item.optString("site_link").takeIf(String::isNotBlank)
                ?.takeIf(LocalNetwork::isAllowedUrl)
            entries[id] = JackettIndexerEntry(
                id = id,
                name = item.optString("name").ifBlank { id }.take(160),
                description = item.optString("description").take(1200),
                siteLink = siteLink,
                alternateSiteLinks = alternateLinks,
                language = item.optString("language").takeIf(String::isNotBlank),
                type = item.optString("type").takeIf(String::isNotBlank),
                configured = item.optBoolean("configured", false),
                categoryIds = categoryIds.distinct().take(100),
                categoryNames = categoryNames.distinct().take(100),
                lastError = item.optString("last_error").takeIf(String::isNotBlank)
                    ?.let { IndexerErrorSanitizer.sanitize(it, configuredSecrets) }
            )
        }
        return entries.values.sortedWith(
            compareBy<JackettIndexerEntry> { !it.configured }
                .thenBy { it.name.lowercase(Locale.ROOT) }
        )
    }

    internal fun parseIndexerConfig(json: String): List<JackettConfigField> {
        require(json.length <= MAX_RESPONSE_BYTES) { "Ответ настроек Jackett слишком большой" }
        val array = runCatching { JSONArray(json) }
            .getOrElse { throw IOException("Jackett вернул некорректные настройки индексатора", it) }
        return buildList {
            for (index in 0 until minOf(array.length(), MAX_CONFIG_FIELDS)) {
                val item = array.optJSONObject(index) ?: continue
                val id = item.optString("id").trim()
                val type = item.optString("type").lowercase(Locale.ROOT)
                if (id.isBlank() || id.length > 120 || type.isBlank()) continue
                val values = item.optJSONArray("values")?.toStringList().orEmpty()
                val optionsObject = item.optJSONObject("options")
                val options = LinkedHashMap<String, String>()
                if (optionsObject != null) {
                    val keys = optionsObject.keys()
                    while (keys.hasNext() && options.size < 300) {
                        val key = keys.next()
                        options[key] = optionsObject.optString(key).take(300)
                    }
                }
                val fieldValue = item.opt("value")?.let { value ->
                    if (value == JSONObject.NULL) "" else value.toString()
                }.orEmpty().take(8_192)
                // Jackett deliberately masks an existing password with this marker.
                // Present an empty editor, but retain the original marker for POST.
                val editableValue = if (
                    type == "password" && fieldValue == JackettConfigField.PASSWORD_REPLACEMENT
                ) "" else fieldValue
                add(
                    JackettConfigField(
                        id = id,
                        type = type,
                        name = item.optString("name").ifBlank { id }.take(160),
                        value = editableValue,
                        originalValue = fieldValue,
                        values = values.take(300),
                        options = options,
                        separator = item.optString("separator").takeIf(String::isNotBlank)?.take(4),
                        delimiters = item.optString("delimiters").takeIf(String::isNotBlank)?.take(200),
                        pattern = item.optString("pattern").takeIf(String::isNotBlank)?.take(300),
                        whitelist = item.optString("whitelist").split(',').map(String::trim)
                            .filter(String::isNotBlank).take(200),
                        blacklist = item.optString("blacklist").split(',').map(String::trim)
                            .filter(String::isNotBlank).take(200)
                    )
                )
            }
        }
    }

    /** Builds the exact id/value(s) array consumed by Jackett's UpdateConfig controller. */
    internal fun buildConfigPayload(fields: List<JackettConfigField>): JSONArray {
        val payload = JSONArray()
        fields.forEach { field ->
            require(field.id.isNotBlank() && field.id.length <= 120) { "Некорректное поле настройки" }
            val item = JSONObject().put("id", field.id)
            when (field.type) {
                "inputcheckbox" -> {
                    val allowed = field.options.keys
                    val safeValues = field.values.distinct().filter { it in allowed }.take(300)
                    item.put("values", JSONArray(safeValues))
                }
                "inputbool" -> item.put("value", field.value.equals("true", ignoreCase = true))
                "password" -> {
                    // Jackett's password marker means "leave the stored secret unchanged".
                    // The UI keeps that intent even after a user types and then clears the field.
                    val passwordValue = if (
                        field.value.isBlank() && field.originalValue == JackettConfigField.PASSWORD_REPLACEMENT
                    ) {
                        JackettConfigField.PASSWORD_REPLACEMENT
                    } else {
                        field.value
                    }
                    item.put("value", passwordValue.take(8_192))
                }
                "inputstring", "inputselect", "inputtags", "hiddendata" ->
                    item.put("value", field.value.take(8_192))
                // Jackett's own dashboard includes an id-only entry for display-only controls.
                "displayinfo", "displayimage" -> Unit
                else -> Unit
            }
            payload.put(item)
        }
        return payload
    }

    private fun execute(
        config: IndexerConfig,
        url: String,
        method: String,
        body: ByteArray? = null
    ): ByteArray {
        if (!LocalNetwork.isAllowedUrl(url)) {
            throw IOException("Jackett должен быть доступен по HTTPS или по локальному HTTP")
        }
        val connection = (URL(url).openConnection() as HttpURLConnection).apply {
            requestMethod = method
            connectTimeout = CONNECT_TIMEOUT_MS
            readTimeout = READ_TIMEOUT_MS
            instanceFollowRedirects = false
            setRequestProperty("Accept", "application/json")
            setRequestProperty("User-Agent", USER_AGENT)
            if (config.cookie.isNotBlank()) setRequestProperty("Cookie", config.cookie.take(8_192))
            if (config.username.isNotBlank() || config.password.isNotBlank()) {
                val credentials = "${config.username}:${config.password}"
                val encoded = java.util.Base64.getEncoder()
                    .encodeToString(credentials.toByteArray(Charsets.UTF_8))
                setRequestProperty("Authorization", "Basic $encoded")
            }
            if (body != null) {
                doOutput = true
                setRequestProperty("Content-Type", "application/json; charset=utf-8")
                setFixedLengthStreamingMode(body.size)
            }
        }
        try {
            if (body != null) connection.outputStream.use { it.write(body) }
            val status = connection.responseCode
            if (status !in 200..299) {
                val message = when (status) {
                    401, 403 -> "Jackett отклонил доступ. Проверьте Cookie авторизованной панели в настройках."
                    404 -> "Jackett не нашёл REST endpoint /api/v2.0/indexers."
                    429 -> "Jackett временно ограничил количество запросов."
                    else -> "Jackett вернул HTTP $status."
                }
                throw IOException(message)
            }
            if (status == HttpURLConnection.HTTP_NO_CONTENT) return ByteArray(0)
            val stream = connection.inputStream
            return stream.use { readLimited(it, MAX_RESPONSE_BYTES) }
        } finally {
            connection.disconnect()
        }
    }

    private fun validateJackettConfig(config: IndexerConfig) {
        require(config.protocol == IndexerProtocol.JACKETT) {
            "Для каталога индексаторов нужен подключённый Jackett"
        }
        require(config.apiKey.isNotBlank()) { "Укажите API-ключ Jackett для поиска Torznab" }
    }

    private fun baseUrl(config: IndexerConfig): String =
        JackettUrl.parseTemplate(config.searchUrlTemplate)?.baseUrl
            ?: throw IOException("Не удалось определить адрес сервера Jackett")

    private fun JSONArray.toStringList(): List<String> = buildList {
        for (i in 0 until minOf(length(), 500)) {
            val value = optString(i).takeIf(String::isNotBlank) ?: continue
            add(value.take(300))
        }
    }

    private fun readLimited(input: java.io.InputStream, maxBytes: Int): ByteArray {
        val output = ByteArrayOutputStream()
        val buffer = ByteArray(8_192)
        var total = 0
        while (true) {
            val count = input.read(buffer)
            if (count < 0) break
            total += count
            if (total > maxBytes) throw IOException("Ответ Jackett слишком большой")
            output.write(buffer, 0, count)
        }
        return output.toByteArray()
    }

package app.jacket.mobile.data

import java.net.Inet6Address
import java.net.InetAddress
import java.net.URI

/**
 * URL policy shared by direct indexers and an optional self-hosted Jackett server.
 *
 * HTTPS may target public providers. Cleartext HTTP is restricted to literal private/loopback/
 * link-local addresses and explicitly local DNS suffixes; generic single-label hosts are rejected
 * because they can resolve outside the local network on some devices.
 */
object LocalNetwork {
    private val localSuffixes = listOf(".local", ".lan", ".home.arpa", ".localhost")

    fun isAllowedUrl(value: String): Boolean = runCatching {
        val uri = URI(value.trim())
        if (uri.rawUserInfo != null || uri.host.isNullOrBlank() || uri.rawFragment != null) return false
        when (uri.scheme?.lowercase()) {
            "https" -> true
            "http" -> isLocalHost(uri.host)
            else -> false
        }
    }.getOrDefault(false)

    fun isLocalHost(rawHost: String): Boolean {
        val host = rawHost.trim().removePrefix("[").removeSuffix("]").trimEnd('.').lowercase()
        if (host.isBlank()) return false
        if (host == "localhost" || host.endsWith(".localhost")) return true
        parseIpv4(host)?.let { return isPrivateIpv4(it) }
        if (host.contains(':')) return isPrivateIpv6(host)
        return localSuffixes.any(host::endsWith)
    }

    private fun parseIpv4(host: String): IntArray? {
        val parts = host.split('.')
        if (parts.size != 4) return null
        val values = IntArray(4)
        for (index in 0..3) {
            val part = parts[index]
            if (part.isEmpty() || part.length > 3 || !part.all(Char::isDigit)) return null
            val value = part.toIntOrNull()?.takeIf { it in 0..255 } ?: return null
            values[index] = value
        }
        return values
    }

    private fun isPrivateIpv4(o: IntArray): Boolean =
        o[0] == 10 ||
            o[0] == 127 ||
            (o[0] == 172 && o[1] in 16..31) ||
            (o[0] == 192 && o[1] == 168) ||
            (o[0] == 169 && o[1] == 254) ||
            (o[0] == 100 && o[1] in 64..127)

    private fun isPrivateIpv6(rawHost: String): Boolean = runCatching {
        // The host contains ':' so it is an IPv6 literal, not a DNS name.
        val literal = rawHost.substringBefore('%')
        val address = InetAddress.getByName(literal)
        if (address !is Inet6Address) return false
        val bytes = address.address
        val loopback = bytes.dropLast(1).all { it == 0.toByte() } && bytes.last() == 1.toByte()
        val uniqueLocal = (bytes[0].toInt() and 0xfe) == 0xfc // fc00::/7
        val linkLocal = (bytes[0].toInt() and 0xff) == 0xfe &&
            (bytes[1].toInt() and 0xc0) == 0x80 // fe80::/10
        loopback || uniqueLocal || linkLocal
    }.getOrDefault(false)
}

/** Normalizes a Jackett dashboard or Torznab URL into its server origin and indexer filter. */
object JackettUrl {
    const val DEFAULT_INDEXER = "all"
    private const val API_PATH = "/api/v2.0/indexers/"
    private const val API_TAIL = "/results/torznab/api"

    data class Parsed(val baseUrl: String, val indexer: String)

    /**
     * Accepts a bare host, a dashboard URL, or a copied Torznab API URL.
     * Local hosts default to HTTP; public hosts default to HTTPS.
     */
    fun normalizeBase(input: String): String? = runCatching {
        var text = input.trim().substringBefore('#').substringBefore('?')
        if (text.isBlank()) return null
        if (!text.contains("://")) {
            val authority = text.substringBefore('/')
            val host = if (authority.startsWith("[")) {
                authority.substringAfter('[').substringBefore(']')
            } else {
                authority.substringBefore(':')
            }
            val scheme = if (LocalNetwork.isLocalHost(host)) "http" else "https"
            text = "$scheme://$text"
        }
        val uri = URI(text)
        if (uri.rawUserInfo != null || uri.host.isNullOrBlank()) return null
        val scheme = uri.scheme?.lowercase() ?: return null
        if (scheme !in setOf("http", "https")) return null

        val rawPath = uri.rawPath.orEmpty().trimEnd('/')
        val lowerPath = rawPath.lowercase()
        val apiAt = lowerPath.indexOf(API_PATH)
        val dashboardAt = listOf("/ui/dashboard", "/ui/").map { lowerPath.indexOf(it) }
            .filter { it >= 0 }.minOrNull()
        val cutAt = listOfNotNull(apiAt.takeIf { it >= 0 }, dashboardAt).minOrNull()
        val basePath = if (cutAt != null) rawPath.substring(0, cutAt) else rawPath

        val normalized = buildString {
            append(scheme).append("://").append(uri.rawAuthority)
            if (basePath.isNotBlank()) append(basePath.trimEnd('/'))
        }
        normalized.takeIf(LocalNetwork::isAllowedUrl)
    }.getOrNull()

    fun searchTemplate(baseUrl: String, indexer: String = DEFAULT_INDEXER): String {
        val id = sanitizeIndexer(indexer)
        return baseUrl.trimEnd('/') + API_PATH + id + API_TAIL + "?t=search&q={query}"
    }

    /** A cheap connection test; the registry preserves this t=caps when adding common parameters. */
    fun capabilitiesTemplate(baseUrl: String, indexer: String = DEFAULT_INDEXER): String {
        val id = sanitizeIndexer(indexer)
        return baseUrl.trimEnd('/') + API_PATH + id + API_TAIL + "?t=caps&q={query}"
    }

    fun parseTemplate(template: String): Parsed? {
        val at = template.indexOf(API_PATH)
        if (at <= 0) return null
        val suffix = template.substring(at + API_PATH.length)
        val indexer = suffix.substringBefore('/')
        val base = template.substring(0, at).trimEnd('/')
        return Parsed(base, indexer.ifBlank { DEFAULT_INDEXER })
    }

    private fun sanitizeIndexer(value: String): String {
        val clean = value.trim().filter { it.isLetterOrDigit() || it in "-_.:" }.take(100)
        return clean.takeUnless { it.isBlank() || it.all { ch -> ch == '.' } } ?: DEFAULT_INDEXER
    }
}

                MediaSection("Популярные фильмы", tmdbList("/3/movie/popular", tmdbToken, MediaKind.MOVIE)),
                MediaSection("Сейчас в тренде", tmdbList("/3/trending/all/week", tmdbToken, MediaKind.MOVIE)),
                MediaSection("Популярные сериалы", tmdbList("/3/tv/popular", tmdbToken, MediaKind.SERIES))
            ).filter { it.items.isNotEmpty() }
        }

        return listOf(
            MediaSection("Открытая коллекция фильмов", archiveSearch("", "mediatype:movies")),
            MediaSection("Документальное кино", archiveSearch("documentary", "mediatype:movies AND subject:documentary")),
            MediaSection("Классика кино", archiveSearch("", "mediatype:movies AND year:[1900 TO 1970]"))

    }

    fun movies(tmdbToken: String): List<CatalogItem> =

        else archiveSearch("", "mediatype:movies")

        if (tmdbToken.isNotBlank()) tmdbList("/3/tv/popular", tmdbToken, MediaKind.SERIES)
        else archiveSearch("television", "mediatype:movies AND subject:television")

    fun search(query: String, tmdbToken: String): List<CatalogItem> {
        val clean = query.trim()
        if (clean.isBlank()) return emptyList()
        val archive = archiveSearch(clean, "mediatype:movies AND (${escapeLucene(clean)})")
        if (tmdbToken.isBlank()) return archive

        val metadata = tmdbSearch(clean, tmdbToken)
        return (metadata + archive).distinctBy { it.id }.take(MAX_RESULTS)
    }

    fun seasons(item: CatalogItem, tmdbToken: String): List<MediaSeason> {
        if (item.kind != MediaKind.SERIES || item.providerId != TMDB_PROVIDER || tmdbToken.isBlank()) return emptyList()
        val json = requestJson("https://api.themoviedb.org/3/tv/${item.providerItemId}?language=ru-RU", bearer = tmdbToken)
        val array = json.optJSONArray("seasons") ?: return emptyList()
        return buildList {
            for (i in 0 until minOf(array.length(), MAX_SEASONS)) {
                val season = array.optJSONObject(i) ?: continue
                val number = season.optInt("season_number", -1)
                if (number <= 0) continue // season 0 is Specials, not a numbered season
                val poster = season.optString("poster_path").takeIf(String::isNotBlank)
                    ?.let { "https://image.tmdb.org/t/p/w500$it" }
                add(
                    MediaSeason(
                        seasonNumber = number,
                        name = season.optString("name").ifBlank { "Сезон $number" },
                        episodeCount = season.optInt("episode_count").coerceAtLeast(0),
                        posterUrl = poster,
                        overview = season.optString("overview")
                    )
                )
            }
        }.sortedBy { it.seasonNumber }
    }

    fun episodes(item: CatalogItem, seasonNumber: Int, tmdbToken: String): List<MediaEpisode> {
        if (item.kind != MediaKind.SERIES || item.providerId != TMDB_PROVIDER || tmdbToken.isBlank() || seasonNumber <= 0) {
            return emptyList()
        }
        val json = requestJson(
            "https://api.themoviedb.org/3/tv/${item.providerItemId}/season/$seasonNumber?language=ru-RU",
            bearer = tmdbToken
        )
        val array = json.optJSONArray("episodes") ?: return emptyList()
        return buildList {
            for (i in 0 until minOf(array.length(), MAX_EPISODES_PER_SEASON)) {
                val episode = array.optJSONObject(i) ?: continue
                val number = episode.optInt("episode_number", -1)
                if (number <= 0) continue
                val still = episode.optString("still_path").takeIf(String::isNotBlank)
                    ?.let { "https://image.tmdb.org/t/p/w500$it" }
                add(
                    MediaEpisode(
                        seasonNumber = seasonNumber,
                        episodeNumber = number,
                        name = episode.optString("name").ifBlank { "Серия $number" },
                        overview = episode.optString("overview"),
                        airDate = episode.optString("air_date").takeIf(String::isNotBlank),
                        stillUrl = still
                    )
                )
            }
        }.sortedBy { it.episodeNumber }
    }

    fun archiveSources(query: String): List<SourceResult> {
        val items = archiveSearch(query, "mediatype:movies AND (${escapeLucene(query)})")
        return items.take(MAX_SOURCE_DETAILS).mapNotNull { item ->
            runCatching { archiveDetails(item).toSourceResult() }.getOrNull()

    fun details(item: CatalogItem): MediaDetails {
        if (item.providerId == ARCHIVE_PROVIDER) return archiveDetails(item)
        val token = ""
        return MediaDetails(
            item = item,
            description = item.overview,
            pageUrl = item.catalogUrl
        )
    }

    fun tmdbDetails(item: CatalogItem, tmdbToken: String): MediaDetails {
        if (item.providerId == ARCHIVE_PROVIDER) return archiveDetails(item)
        if (tmdbToken.isBlank()) return details(item)
        val mediaPath = if (item.kind == MediaKind.SERIES) "tv" else "movie"
        val json = requestJson("https://api.themoviedb.org/3/$mediaPath/${item.providerItemId}?language=ru-RU", bearer = tmdbToken)
        val overview = json.optString("overview").ifBlank { item.overview }
        val runtime = when (item.kind) {
            MediaKind.MOVIE -> json.optInt("runtime").takeIf { it > 0 }?.let { "${it} мин." }
            MediaKind.SERIES -> json.optJSONObject("episode_run_time")?.optInt("0")?.takeIf { it > 0 }?.let { "${it} мин. серия" }
                ?: json.optJSONArray("episode_run_time")?.optInt(0)?.takeIf { it > 0 }?.let { "${it} мин. серия" }
            else -> null
        }
        val genres = json.optJSONArray("genres")?.joinStrings("name")
        val summary = listOfNotNull(overview, genres?.takeIf { it.isNotBlank() }?.let { "Жанры: $it" }).joinToString("\n\n")
        return MediaDetails(item, summary, runtime = runtime, pageUrl = item.catalogUrl)
    }

    fun archiveDetails(item: CatalogItem): MediaDetails {
        val json = requestJson("https://archive.org/metadata/${Uri.encode(item.providerItemId)}")
        val metadata = json.optJSONObject("metadata") ?: JSONObject()
        val files = json.optJSONArray("files") ?: JSONArray()
        val license = metadata.optString("licenseurl").takeIf(String::isNotBlank) ?: item.licenseUrl
        val creator = metadata.firstText("creator", "artist", "director")
        val description = metadata.firstText("description", "abstract").ifBlank { item.overview }
        val runtime = metadata.firstText("runtime", "length").takeIf(String::isNotBlank)
        val mediaFile = findVideoFile(files)
        val torrentFile = findTorrentFile(files)
        val streamUrl = if (isKnownOpenLicense(license) && mediaFile != null) {
            downloadUrl(item.providerItemId, mediaFile.first)
        } else null
        val torrentUrl = if (isKnownOpenLicense(license) && torrentFile != null) {
            downloadUrl(item.providerItemId, torrentFile.first)
        } else null

        return MediaDetails(
            item = item.copy(licenseUrl = license),
            description = description,
            creator = creator,
            runtime = runtime,
            licenseUrl = license,
            streamUrl = streamUrl,
            torrentUrl = torrentUrl,
            pageUrl = "https://archive.org/details/${Uri.encode(item.providerItemId)}",
            fileSizeBytes = mediaFile?.second
        )
    }

    private fun tmdbList(path: String, token: String, defaultKind: MediaKind): List<CatalogItem> {
        val json = requestJson("https://api.themoviedb.org$path?language=ru-RU&page=1", bearer = token)
        val array = json.optJSONArray("results") ?: return emptyList()
        return buildList {
            for (i in 0 until minOf(array.length(), MAX_RESULTS)) {
                val item = array.optJSONObject(i) ?: continue
                val actualKind = when (item.optString("media_type")) {
                    "tv" -> MediaKind.SERIES
                    "movie" -> MediaKind.MOVIE
                    else -> defaultKind
                }
                tmdbItem(item, actualKind)?.let(::add)
            }
        }
    }

    private fun tmdbSearch(query: String, token: String): List<CatalogItem> {
        val uri = Uri.parse("https://api.themoviedb.org/3/search/multi")
            .buildUpon()
            .appendQueryParameter("query", query)
            .appendQueryParameter("language", "ru-RU")
            .appendQueryParameter("include_adult", "false")
            .build()
        val json = requestJson(uri.toString(), bearer = token)
        val array = json.optJSONArray("results") ?: return emptyList()
        return buildList {
            for (i in 0 until minOf(array.length(), MAX_RESULTS)) {
                val obj = array.optJSONObject(i) ?: continue
                val kind = when (obj.optString("media_type")) {
                    "tv" -> MediaKind.SERIES
                    "movie" -> MediaKind.MOVIE
                    else -> continue
                }
                tmdbItem(obj, kind)?.let(::add)
            }
        }
    }

    private fun tmdbItem(obj: JSONObject, kind: MediaKind): CatalogItem? {
        val id = obj.optLong("id")
        if (id <= 0L) return null
        val title = obj.optString(if (kind == MediaKind.SERIES) "name" else "title")
            .ifBlank { obj.optString("original_title").ifBlank { obj.optString("original_name") } }
            .takeIf(String::isNotBlank) ?: return null
        val poster = obj.optString("poster_path").takeIf(String::isNotBlank)
            ?.let { "https://image.tmdb.org/t/p/w500$it" }
        val backdrop = obj.optString("backdrop_path").takeIf(String::isNotBlank)
            ?.let { "https://image.tmdb.org/t/p/w1280$it" }
        val date = obj.optString(if (kind == MediaKind.SERIES) "first_air_date" else "release_date")
            .takeIf(String::isNotBlank)
        return CatalogItem(
            id = "tmdb:${kind.name.lowercase()}:$id",
            providerId = TMDB_PROVIDER,
            providerItemId = id.toString(),
            kind = kind,
            title = title,
            overview = obj.optString("overview"),
            posterUrl = poster,
            backdropUrl = backdrop,
            releaseDate = date,
            rating = if (obj.isNull("vote_average")) null else obj.optDouble("vote_average"),
            popularity = obj.optDouble("popularity"),
            catalogUrl = "https://www.themoviedb.org/${if (kind == MediaKind.SERIES) "tv" else "movie"}/$id"
        )
    }

    private fun archiveSearch(searchText: String, query: String): List<CatalogItem> {
        val uriBuilder = Uri.parse("https://archive.org/advancedsearch.php").buildUpon()
            .appendQueryParameter("q", query)
            .appendQueryParameter("rows", MAX_RESULTS.toString())
            .appendQueryParameter("page", "1")
            .appendQueryParameter("output", "json")
            .appendQueryParameter("sort[]", "downloads desc")
        ARCHIVE_FIELDS.forEach { uriBuilder.appendQueryParameter("fl[]", it) }
        val json = requestJson(uriBuilder.build().toString())
        val docs = json.optJSONObject("response")?.optJSONArray("docs") ?: return emptyList()
        return buildList {
            for (i in 0 until minOf(docs.length(), MAX_RESULTS)) {
                val doc = docs.optJSONObject(i) ?: continue
                val id = doc.optString("identifier").takeIf(String::isNotBlank) ?: continue
                val title = doc.optString("title").ifBlank { id }
                val license = doc.firstText("licenseurl").takeIf(String::isNotBlank)
                val description = doc.firstText("description")
                val creator = doc.firstText("creator")
                val year = doc.firstText("year", "date").take(4)
                val subjects = doc.joinStrings("subject")
                val overview = listOfNotNull(
                    description.takeIf(String::isNotBlank),
                    creator.takeIf(String::isNotBlank)?.let { "Автор: $it" },
                    subjects.takeIf(String::isNotBlank)
                ).joinToString("\n")
                add(
                    CatalogItem(
                        id = "archive:$id",
                        providerId = ARCHIVE_PROVIDER,
                        providerItemId = id,
                        kind = MediaKind.MOVIE,
                        title = title,
                        overview = overview,
                        posterUrl = "https://archive.org/services/img/${Uri.encode(id)}",
                        releaseDate = year.takeIf { it.length == 4 },
                        popularity = doc.optDouble("downloads"),
                        licenseUrl = license,
                        catalogUrl = "https://archive.org/details/${Uri.encode(id)}"
                    )
                )
            }
        }.distinctBy { it.id }
    }

    private fun isKnownOpenLicense(value: String?): Boolean {
        if (value.isNullOrBlank()) return false
        val uri = runCatching { Uri.parse(value) }.getOrNull() ?: return false
        val host = uri.host?.lowercase() ?: return false
        val path = uri.path.orEmpty().lowercase()
        return host == "creativecommons.org" &&
            (path.startsWith("/licenses/") || path.startsWith("/publicdomain/"))
    }

    private fun findVideoFile(files: JSONArray): Pair<String, Long?>? {
        val preferred = listOf(".mp4", ".m4v", ".webm", ".ogv", ".mov", ".mkv")
        val candidates = buildList {
            for (i in 0 until files.length()) {
                val file = files.optJSONObject(i) ?: continue
                val name = file.optString("name")
                val format = file.optString("format")
                if (name.substringAfterLast('.', "").lowercase().let { ext -> ".$ext" in preferred } ||
                    format.contains("mpeg4", true) || format.contains("h.264", true) || format.contains("ogg video", true)
                ) {
                    val size = file.optString("size").toLongOrNull()?.takeIf { it > 0L }
                    add(name to size)
                }
            }
        }
        return candidates.minByOrNull { candidate ->
            val ext = candidate.first.substringAfterLast('.', "").lowercase()
            preferred.indexOf(".$ext").let { if (it < 0) Int.MAX_VALUE else it }
        }
    }

    private fun findTorrentFile(files: JSONArray): Pair<String, Long?>? {
        for (i in 0 until files.length()) {
            val file = files.optJSONObject(i) ?: continue
            val name = file.optString("name")
            if (name.endsWith(".torrent", ignoreCase = true)) {
                return name to file.optString("size").toLongOrNull()
            }
        }
        return null
    }

    private fun downloadUrl(identifier: String, filename: String): String =
        "https://archive.org/download/${Uri.encode(identifier)}/${Uri.encode(filename)}"

    private fun requestJson(url: String, bearer: String? = null): JSONObject {
        val connection = (URL(url).openConnection() as HttpURLConnection).apply {
            requestMethod = "GET"
            connectTimeout = CONNECT_TIMEOUT_MS
            readTimeout = READ_TIMEOUT_MS
            instanceFollowRedirects = false
            setRequestProperty("Accept", "application/json, application/rss+xml;q=0.8")
            setRequestProperty("User-Agent", USER_AGENT)
            if (!bearer.isNullOrBlank()) setRequestProperty("Authorization", "Bearer $bearer")
        }
        try {
            val status = connection.responseCode
            if (status !in 200..299) throw IOException("Источник вернул HTTP $status")
            val body = readBounded(connection.inputStream, MAX_RESPONSE_BYTES)
            return JSONObject(body.toString(Charsets.UTF_8))
        } finally {
            connection.disconnect()
        }
    }

    private fun readBounded(stream: java.io.InputStream, maxBytes: Int): ByteArray =
        stream.use { input ->
            val output = ByteArrayOutputStream()
            val buffer = ByteArray(8192)
            var total = 0
            while (true) {
                val count = input.read(buffer)
                if (count < 0) break
                total += count
                if (total > maxBytes) throw IOException("Ответ источника слишком большой")
                output.write(buffer, 0, count)
            }
            output.toByteArray()
        }

    private fun JSONArray.joinStrings(key: String): String = buildList {
        for (i in 0 until length()) {
            val value = opt(i)
            when (value) {
                is JSONObject -> value.optString(key).takeIf(String::isNotBlank)?.let(::add)
                is String -> value.takeIf(String::isNotBlank)?.let(::add)
            }
        }
    }.joinToString(", ")

    private fun JSONObject.joinStrings(key: String): String {
        val value = opt(key)
        return when (value) {
            is JSONArray -> (0 until value.length()).mapNotNull { value.optString(it).takeIf(String::isNotBlank) }.joinToString(", ")
            is String -> value
            else -> ""
        }
    }

    private fun JSONObject.firstText(vararg keys: String): String {
        keys.forEach { key ->
            val value = opt(key)
            val text = when (value) {
                is JSONArray -> (0 until value.length()).mapNotNull { value.optString(it).takeIf(String::isNotBlank) }.joinToString(", ")
                is String -> value
                else -> ""
            }
            if (text.isNotBlank()) return text
        }
        return ""
    }

    private fun MediaDetails.toSourceResult(): SourceResult? {
        val detail = this
        if (detail.streamUrl == null && detail.torrentUrl == null) return null
        return SourceResult(
            id = detail.item.id,
            title = detail.item.title,
            providerName = "Internet Archive",
            downloadUrl = detail.torrentUrl,
            streamUrl = detail.streamUrl,
            sizeBytes = detail.fileSizeBytes,
            licenseUrl = detail.licenseUrl,
            pageUrl = detail.pageUrl,
            sourceType = if (detail.streamUrl != null) {
                MediaSourceType.LICENSED_DIRECT
            } else {
                MediaSourceType.TORRENT
            }
        )
    }

    private fun escapeLucene(value: String): String =
        value.replace(Regex("([+\\-!(){}\\[\\]^\"~*?:\\\\/])"), "\\\\$1").take(120)

    private fun JSONObject.firstText(key: String): String = opt(key).let { value ->
        when (value) {
            is JSONArray -> (0 until value.length()).joinToString(", ") { value.optString(it) }
            is String -> value
            else -> ""
        }
    }

    private companion object {
        const val TMDB_PROVIDER = "tmdb"
        const val ARCHIVE_PROVIDER = "archive"
        const val MAX_RESULTS = 24
        const val MAX_SEASONS = 40
        const val MAX_EPISODES_PER_SEASON = 100
        const val MAX_SOURCE_DETAILS = 8
        const val CONNECT_TIMEOUT_MS = 12_000
        const val READ_TIMEOUT_MS = 25_000
        const val MAX_RESPONSE_BYTES = 6 * 1024 * 1024
        const val USER_AGENT = "JacketAndroid/2.0 (Android media client)"
        val ARCHIVE_FIELDS = listOf(
            "identifier", "title", "description", "year", "date", "creator",
            "licenseurl", "downloads", "subject", "runtime", "collection"
        )
    }
}

/** Local settings. TMDB and all indexer credentials are encrypted with Android Keystore. */
/**
 * Explicitly restoring the built-in list also re-enables presets the user had
 * previously switched off, while preserving custom sites and their settings.
 */
internal fun mergeTrackerShortcuts(
    current: List<WebSearchProvider>,
    defaults: List<WebSearchProvider>,
    limit: Int
): List<WebSearchProvider> {
    val defaultIds = defaults.mapTo(hashSetOf()) { it.id }
    val reEnabled = current.map { provider ->
        if (provider.id in defaultIds) provider.copy(enabled = true) else provider
    }
    return (reEnabled + defaults).distinctBy { it.id }.take(limit)
}

class MediaSettingsStore(context: Context) {
    private val preferences = context.applicationContext.getSharedPreferences(PREFERENCES, Context.MODE_PRIVATE)

    fun tmdbToken(): String = decrypt(preferences.getString(KEY_TMDB_TOKEN, null))

    fun saveTmdbToken(token: String) {
        preferences.edit { putString(KEY_TMDB_TOKEN, encrypt(token.trim())) }
    }

    fun filmixToken(): String = decrypt(preferences.getString(KEY_FILMIX_TOKEN, null))

    fun filmixApiBase(): String = runCatching {
        FilmixDeviceAuth.normalizeApiBase(
            preferences.getString(KEY_FILMIX_API_BASE, FilmixDeviceAuth.DEFAULT_API_BASE)
                ?: FilmixDeviceAuth.DEFAULT_API_BASE
        )
    }.getOrDefault(FilmixDeviceAuth.DEFAULT_API_BASE)

    @Synchronized
    fun saveFilmixApiBase(value: String): String {
        val normalized = FilmixDeviceAuth.normalizeApiBase(value)
        preferences.edit { putString(KEY_FILMIX_API_BASE, normalized) }
        return normalized
    }

    @Synchronized
    fun saveFilmixToken(token: String) {
        preferences.edit { putString(KEY_FILMIX_TOKEN, encrypt(token.trim())) }
    }

    @Synchronized
    fun clearFilmixToken() {
        preferences.edit { remove(KEY_FILMIX_TOKEN) }
    }

    /** Stable per-install identifier required by Filmix's device-code endpoint. */
    @Synchronized
    fun filmixDeviceId(): String {
        preferences.getString(KEY_FILMIX_DEVICE_ID, null)
            ?.takeIf { it.matches(Regex("[a-fA-F0-9]{16}")) }
            ?.let { return it }
        val bytes = ByteArray(8).also(java.security.SecureRandom()::nextBytes)
        val id = bytes.joinToString("") { "%02x".format(it.toInt() and 0xff) }
        preferences.edit { putString(KEY_FILMIX_DEVICE_ID, id) }
        return id
    }

    fun hdRezkaSettings(): HdRezkaSettings {
        val cookie = decrypt(preferences.getString(KEY_HDREZKA_COOKIE, null))
        return HdRezkaSettings(
            mirror = preferences.getString(KEY_HDREZKA_MIRROR, "") ?: "",
            login = decrypt(preferences.getString(KEY_HDREZKA_LOGIN, null)),
            password = decrypt(preferences.getString(KEY_HDREZKA_PASSWORD, null)),
            cookie = cookie,
            connected = preferences.getBoolean(KEY_HDREZKA_CONNECTED, false) &&
                HdRezkaLoginClient.hasAuthenticatedCookie(cookie)
        )
    }

    @Synchronized
    fun saveHdRezkaSettings(settings: HdRezkaSettings) {
        val mirror = settings.mirror.trim().take(300).let {
            if (it.isBlank()) "" else HdRezkaLoginClient.validateMirror(it)
        }
        val login = settings.login.replace(Regex("[\\r\\n]"), "").trim().take(256)
        val password = settings.password.take(512)
        val cookie = settings.cookie.replace(Regex("[\\r\\n]"), "").trim().take(8_192)
        preferences.edit {
            putString(KEY_HDREZKA_MIRROR, mirror)
            putString(KEY_HDREZKA_LOGIN, encrypt(login))
            putString(KEY_HDREZKA_PASSWORD, encrypt(password))
            putString(KEY_HDREZKA_COOKIE, encrypt(cookie))
            putBoolean(
                KEY_HDREZKA_CONNECTED,
                settings.connected && HdRezkaLoginClient.hasAuthenticatedCookie(cookie)
            )
        }
    }

    @Synchronized
    fun disconnectHdRezka() {
        val current = hdRezkaSettings()
        saveHdRezkaSettings(current.copy(cookie = "", connected = false))
    }

    fun indexers(): List<IndexerConfig> = runCatching {
        val array = JSONArray(preferences.getString(KEY_INDEXERS, "[]"))
        buildList {
            for (i in 0 until array.length()) {
                val item = array.optJSONObject(i) ?: continue
                val config = IndexerConfig(
                    id = item.optString("id"),
                    name = item.optString("name"),
                    searchUrlTemplate = item.optString("url"),
                    protocol = runCatching {
                        IndexerProtocol.valueOf(item.optString("protocol", "RSS"))
                    }.getOrDefault(IndexerProtocol.RSS),
                    apiKey = decrypt(item.optString("apiKeyEnc")),
                    username = decrypt(item.optString("usernameEnc")),
                    password = decrypt(item.optString("passwordEnc")),
                    cookie = decrypt(item.optString("cookieEnc")),
                    categories = item.optString("categories"),
                    tags = item.optString("tags"),
                    freeleechOnly = item.optBoolean("freeleechOnly", false),
                    sortBy = item.optString("sortBy", "created"),
                    sortOrder = item.optString("sortOrder", "desc"),
                    enabled = item.optBoolean("enabled", true)
                )
                if (config.id.isNotBlank() && config.name.isNotBlank() && isValidTemplate(config.searchUrlTemplate)) {
                    add(config)
                }
            }
        }.distinctBy { it.id }.take(MAX_INDEXERS)
    }.getOrDefault(emptyList())

    /** Upsert also supports editing an existing indexer without losing its stable ID. */
    @Synchronized
    fun saveIndexer(config: IndexerConfig): IndexerConfig {
        require(config.name.isNotBlank()) { "Укажите название индексатора" }
        require(isValidTemplate(config.searchUrlTemplate)) {
            "Нужен HTTPS URL либо HTTP-адрес локального сервера с маркером {query}. Для Torznab: /api?t=search&q={query}"
        }
        val normalized = config.copy(
            id = config.id.ifBlank { UUID.randomUUID().toString() },
            name = config.name.trim().take(80),
            searchUrlTemplate = config.searchUrlTemplate.trim(),
            apiKey = config.apiKey.replace(Regex("[\\r\\n]"), "").trim().take(512),
            username = config.username.replace(Regex("[\\r\\n]"), "").trim().take(256),
            password = config.password.take(512),
            // Prevent custom auth values from injecting HTTP headers.
            cookie = config.cookie.replace(Regex("[\\r\\n]"), "").trim().take(4096),
            categories = config.categories.trim().take(500),
            tags = config.tags.trim().take(300),
            sortBy = config.sortBy.trim().take(40).ifBlank { "created" },
            sortOrder = config.sortOrder.trim().lowercase().takeIf { it in setOf("asc", "desc") } ?: "desc"
        )
        val current = indexers().filterNot { it.id == normalized.id }
        require(current.size < MAX_INDEXERS) { "Достигнут лимит в $MAX_INDEXERS индексаторов" }
        saveIndexers(current + normalized)
        return normalized
    }

    @Synchronized
    fun addIndexer(name: String, urlTemplate: String) {
        saveIndexer(IndexerConfig(id = "", name = name, searchUrlTemplate = urlTemplate))
    }

    /** Export only non-secret fields; authentication must be re-entered after import. */
    fun exportIndexersJson(): String {
        val root = JSONArray()
        indexers().forEach { item ->
            root.put(
                JSONObject()
                    .put("name", item.name)
                    .put("url", item.searchUrlTemplate)
                    .put("protocol", item.protocol.name)
                    .put("categories", item.categories)
                    .put("tags", item.tags)
                    .put("freeleechOnly", item.freeleechOnly)
                    .put("sortBy", item.sortBy)
                    .put("sortOrder", item.sortOrder)
                    .put("enabled", item.enabled)
            )
        }
        return root.toString(2)
    }

    /** Import replaces nothing: each validated source is added with blank credentials. */
    @Synchronized
    fun importIndexersJson(json: String): Int {
        require(json.length <= MAX_IMPORT_BYTES) { "Файл настроек слишком большой" }
        val root = JSONArray(json)
        var imported = 0
        for (i in 0 until minOf(root.length(), MAX_INDEXERS)) {
            val item = root.optJSONObject(i) ?: continue
            val config = runCatching {
                IndexerConfig(
                    id = "",
                    name = item.optString("name"),
                    searchUrlTemplate = item.optString("url"),
                    protocol = runCatching { IndexerProtocol.valueOf(item.optString("protocol", "RSS")) }
                        .getOrDefault(IndexerProtocol.RSS),
                    categories = item.optString("categories"),
                    tags = item.optString("tags"),
                    freeleechOnly = item.optBoolean("freeleechOnly", false),
                    sortBy = item.optString("sortBy", "created"),
                    sortOrder = item.optString("sortOrder", "desc"),
                    enabled = item.optBoolean("enabled", true)
                )
            }.getOrNull() ?: continue
            if (runCatching { saveIndexer(config) }.isSuccess) imported++
        }
        return imported
    }

    fun setIndexerEnabled(id: String, enabled: Boolean) {

    private fun encrypt(value: String): String {
        if (value.isBlank()) return ""
        val cipher = Cipher.getInstance(TRANSFORMATION)
        cipher.init(Cipher.ENCRYPT_MODE, getOrCreateKey())
        val encrypted = cipher.doFinal(value.toByteArray(Charsets.UTF_8))
        val payload = ByteBuffer.allocate(cipher.iv.size + encrypted.size).put(cipher.iv).put(encrypted).array()
        return Base64.encodeToString(payload, Base64.NO_WRAP)
    }

    private fun decrypt(value: String?): String {
        if (value.isNullOrBlank()) return ""
        return runCatching {
            val buffer = ByteBuffer.wrap(Base64.decode(value, Base64.NO_WRAP))
            require(buffer.remaining() > GCM_IV_LENGTH)
            val iv = ByteArray(GCM_IV_LENGTH).also(buffer::get)
            val encrypted = ByteArray(buffer.remaining()).also(buffer::get)
            val cipher = Cipher.getInstance(TRANSFORMATION)
            cipher.init(Cipher.DECRYPT_MODE, getOrCreateKey(), GCMParameterSpec(GCM_TAG_LENGTH_BITS, iv))
            String(cipher.doFinal(encrypted), Charsets.UTF_8)
        }.getOrDefault("")
    }

    private fun getOrCreateKey(): SecretKey {
        val keyStore = KeyStore.getInstance(ANDROID_KEYSTORE).apply { load(null) }
        (keyStore.getKey(KEY_ALIAS, null) as? SecretKey)?.let { return it }
        val generator = KeyGenerator.getInstance(KeyProperties.KEY_ALGORITHM_AES, ANDROID_KEYSTORE)
        generator.init(
            KeyGenParameterSpec.Builder(
                KEY_ALIAS,
                KeyProperties.PURPOSE_ENCRYPT or KeyProperties.PURPOSE_DECRYPT
            )
                .setBlockModes(KeyProperties.BLOCK_MODE_GCM)
                .setEncryptionPaddings(KeyProperties.ENCRYPTION_PADDING_NONE)
                .setRandomizedEncryptionRequired(true)
                .build()
        )
        return generator.generateKey()
    }

    private fun isValidTemplate(value: String): Boolean = runCatching {
        if (!value.contains("{query}")) return false
        LocalNetwork.isAllowedUrl(value.replace("{query}", "probe").replace("{apikey}", "test"))
    }.getOrDefault(false)

package app.jacket.mobile.data

/** Small title-only release classifier. These tags are heuristics, not tracker-specific metadata. */
object ReleaseHeuristics {
    private val resolutionPatterns = listOf(
        "2160p" to Regex("""(?i)(?<![a-z0-9])(?:2160p|4k|uhd)(?![a-z0-9])"""),
        "1080p" to Regex("""(?i)(?<![a-z0-9])1080[pi]?(?![a-z0-9])"""),

    fun classify(title: String): ReleaseMetadata {
        val quality = resolutionPatterns.firstOrNull { it.second.containsMatchIn(title) }?.first
        val hdr = Regex("""(?i)(?<![a-z0-9])hdr(?:10\+?)?(?![a-z0-9])""").containsMatchIn(title)
        val dolbyVision = Regex("""(?i)(?<![a-z0-9])(?:dolby[ ._-]?vision|dv)(?![a-z0-9])""").containsMatchIn(title)
        val codec = when {
            Regex("""(?i)(?<![a-z0-9])(?:hevc|h\.265|x265)(?![a-z0-9])""").containsMatchIn(title) -> "HEVC / H.265"
            Regex("""(?i)(?<![a-z0-9])(?:av1)(?![a-z0-9])""").containsMatchIn(title) -> "AV1"
            Regex("""(?i)(?<![a-z0-9])(?:avc|h\.264|x264)(?![a-z0-9])""").containsMatchIn(title) -> "AVC / H.264"
            else -> null
        }
        val audio = audioPatterns.filter { it.second.containsMatchIn(title) }.map { it.first }
        val source = sourcePatterns.filter { it.second.containsMatchIn(title) }.map { it.first } +
            listOf("DUB", "MVO", "AVO", "VO", "LE", "LostFilm", "NewStudio").filter {
                Regex("""(?i)(?<![a-z0-9])${Regex.escape(it)}(?![a-z0-9])""").containsMatchIn(title)
            }
        val dimensions = dimensionPattern.find(title)?.let { "${it.groupValues[1]}x${it.groupValues[2]}" }
        val channelCount = channelPattern.find(title)?.groupValues?.getOrNull(1)
        val subtitleLanguages = subtitlePattern.findAll(title).mapNotNull { match ->
            (match.groupValues.getOrNull(1).orEmpty().ifBlank { match.groupValues.getOrNull(2).orEmpty() })
                .uppercase().takeIf(String::isNotBlank)
        }.distinct().toList()
        val foundLanguages = languageNames.mapNotNull { (code, pattern) ->
            code.takeIf { pattern.containsMatchIn(title) }
        }
        val audioLanguages = foundLanguages.filterNot { it in subtitleLanguages }
        val bitrate = bitratePattern.find(title)?.groupValues?.getOrNull(1)?.replace(',', '.')?.let { "$it Мбит/с" }
        val displayQuality = quality ?: when {
            dimensions?.startsWith("3840") == true -> "2160p"
            dimensions?.startsWith("1920") == true -> "FHD"
            dimensions?.startsWith("1280") == true -> "720p"
            else -> null
        }
        return ReleaseMetadata(
            quality = displayQuality,
            hdr = hdr,
            dolbyVision = dolbyVision,
            videoCodec = codec,
            audioTags = audio.distinct(),
            sourceTags = source.distinct(),
            resolutionDimensions = dimensions,
            audioChannels = channelCount,
            audioLanguages = audioLanguages,
            subtitleLanguages = subtitleLanguages,
            bitrate = bitrate
        )
    }

fun formatBytes(bytes: Long?): String {
    if (bytes == null || bytes <= 0L) return "Размер неизвестен"
    val units = arrayOf("Б", "КБ", "МБ", "ГБ", "ТБ")
    var value = bytes.toDouble()
    var unit = 0
    while (value >= 1024.0 && unit < units.lastIndex) {
        value /= 1024.0
        unit++
    }
    return if (unit == 0) "${value.toLong()} ${units[unit]}"
    else String.format(Locale.ROOT, "%.1f %s", value, units[unit])
}

    internal fun buildSearchUrl(provider: WebSearchProvider, query: String): String {
        val profile = profiles[provider.id]
            ?: throw IllegalArgumentException("Для этого сайта нет встроенного парсера")
        require(query.isNotBlank()) { "Введите название для поиска" }
        val template = WebSearchUrlBuilder.validateTemplate(provider.searchUrlTemplate)
        val encoded = URLEncoder.encode(query.trim(), profile.charset.name()).replace("+", "%20")

    /**
     * Searches up to six enabled built-in trackers concurrently, with a strict
     * per-provider concurrency cap. Partial results are retained if one site fails.
     */
    private data class ProviderSearchOutcome(
        val provider: WebSearchProvider,
        val results: List<SourceResult> = emptyList(),
        val error: String? = null
    )

    /**
     * Searches enabled trackers concurrently and publishes a merged snapshot each
     * time one finishes. Results are collected in completion order, not provider
     * settings order, and the whole batch has a hard time budget.
     */
    internal fun searchAll(
        providers: List<WebSearchProvider>,
        query: String,
        onUpdate: (TrackerSearchBatchOutcome) -> Unit = {}
    ): TrackerSearchBatchOutcome {
        require(query.isNotBlank()) { "Введите название для поиска" }
        val active = providers
            .filter { it.enabled && supports(it.id) }
            .distinctBy { it.id }
            .take(6)
        require(active.isNotEmpty()) { "Нет включённых встроенных трекеров" }

        val tasks = active.map { provider ->
            Callable {
                try {
                    ProviderSearchOutcome(provider, search(provider, query.trim()))
                } catch (error: Exception) {
                    val cause = error.cause ?: error
                    ProviderSearchOutcome(
                        provider = provider,
                        error = cause.message?.take(160) ?: cause.javaClass.simpleName
                    )
                }
            }
        }
        val batches = ArrayList<List<SourceResult>>(active.size)
        val failures = ArrayList<String>()
        val completedIds = HashSet<String>()
        var completedProviders = 0

        fun snapshot(timedOut: Boolean = false) = TrackerSearchBatchOutcome(
            results = mergeResults(batches),
            failures = failures.toList(),
            completedProviders = completedProviders,
            totalProviders = active.size,
            timedOut = timedOut
        )

        val completed = CompletionOrderCollector.collect(
            tasks = tasks,
            timeoutMs = SEARCH_ALL_TIMEOUT_MS,
            maxConcurrency = 3
        ) { result ->
            completedProviders++
            result.fold(
                onSuccess = { outcome ->
                    completedIds += outcome.provider.id
                    if (outcome.error != null) {
                        failures += "${outcome.provider.name}: ${outcome.error}"
                    } else {
                        batches += outcome.results
                    }
                },
                onFailure = { error ->
                    failures += "Ошибка обработчика трекера: ${error.message?.take(160) ?: error.javaClass.simpleName}"
                }
            )
            runCatching { onUpdate(snapshot()) }
        }

        val timedOut = completed < active.size
        if (timedOut) {
            active.filterNot { it.id in completedIds }.forEach { provider ->
                failures += "${provider.name}: превышено время поиска (25 секунд)"
            }
        }
        return snapshot(timedOut).also { outcome ->
            runCatching { onUpdate(outcome) }
        }
    }

    /** Merges provider batches by BitTorrent info-hash and keeps the healthiest duplicate. */
    internal fun mergeResults(batches: List<List<SourceResult>>): List<SourceResult> {
        val merged = LinkedHashMap<String, SourceResult>()
        batches.flatten().forEach { source ->
            val key = magnetInfoHash(source.magnetUri)
                ?: source.downloadUrl
                ?: source.id
            val current = merged[key]
            if (current == null || (source.seeders ?: -1) > (current.seeders ?: -1)) {
                merged[key] = source
            }
        }
        return merged.values
            .sortedWith(
                compareByDescending<SourceResult> { it.seeders ?: -1 }
                    .thenByDescending { it.sizeBytes ?: -1L }
                    .thenBy { it.title.lowercase(Locale.ROOT) }
            )
            .take(MAX_RESULTS * 6)
    }

    fun search(provider: WebSearchProvider, query: String): List<SourceResult> {
        val profile = profiles[provider.id]
            ?: throw IllegalArgumentException("Для этого сайта нет встроенного парсера")
        require(provider.enabled) { "Трекер отключён" }
        require(query.isNotBlank()) { "Введите название для поиска" }

        val searchUrl = buildSearchUrl(provider, query)
        val originalHost = URI(searchUrl).host
        val searchPage = fetchHtml(searchUrl, provider.cookie, originalHost, profile.charset)
        ensureNotChallenge(searchPage.html, provider.name)
        val candidates = parseListing(searchPage.html, searchPage.finalUrl, provider.id)
        if (candidates.isEmpty()) {
            throw IOException(
                "${provider.name}: не удалось распознать результаты. Возможно, сайт изменил разметку " +
                    "или требует вход через браузер."
            )
        }

        val detailRequests = candidates.withIndex()
            .filter { (_, item) ->
                item.magnet == null && item.torrentUrl == null && item.pageUrl != null
            }
            .take(MAX_DETAIL_PAGES)
            .map { it.index to it.value.pageUrl!! }

        val details = resolveDetailsConcurrently(
            detailRequests, provider, originalHost, profile.charset
        )

        val resolved = candidates.mapIndexedNotNull { index, candidate ->
            val detailLinks = details[index]
            val magnet = candidate.magnet ?: detailLinks?.first
            val torrent = candidate.torrentUrl ?: detailLinks?.second
            if (magnet == null && torrent == null) return@mapIndexedNotNull null

            val identity = magnetInfoHash(magnet) ?: torrent ?: candidate.pageUrl ?: candidate.title
            SourceResult(
                id = "${provider.id}:${identity.lowercase(Locale.ROOT).hashCode()}",
                title = candidate.title,
                providerName = "Встроенный парсер",
                magnetUri = magnet,
                downloadUrl = torrent,
                sizeBytes = candidate.sizeBytes,
                seeders = candidate.seeders,
                leechers = candidate.leechers,
                pageUrl = candidate.pageUrl,
                indexerId = provider.id,
                tracker = provider.name
            )
        }

        return resolved
            .distinctBy { magnetInfoHash(it.magnetUri) ?: it.downloadUrl ?: it.id }
            .sortedWith(
                compareByDescending<SourceResult> { it.seeders ?: -1 }
                    .thenBy { it.title.lowercase(Locale.ROOT) }
            )
            .take(MAX_RESULTS)
    }

    private fun resolveDetailsConcurrently(
        pages: List<Pair<Int, String>>,
        provider: WebSearchProvider,
        originalHost: String,
        fallbackCharset: Charset
    ): Map<Int, Pair<String?, String?>> {
        if (pages.isEmpty()) return emptyMap()
        val tasks = pages.map { (index, url) ->
            Callable {
                val page = fetchHtml(
                    url,
                    provider.cookie,
                    originalHost,
                    fallbackCharset,
                    connectTimeoutMs = DETAIL_CONNECT_TIMEOUT_MS,
                    readTimeoutMs = DETAIL_READ_TIMEOUT_MS
                )
                ensureNotChallenge(page.html, provider.name)
                index to parseDownloadLinks(page.html, page.finalUrl)
            }
        }
        val details = LinkedHashMap<Int, Pair<String?, String?>>()
        CompletionOrderCollector.collect(
            tasks = tasks,
            timeoutMs = DETAIL_RESOLUTION_TIMEOUT_MS,
            maxConcurrency = MAX_DETAIL_CONCURRENCY
        ) { result ->
            result.getOrNull()?.let { (index, links) -> details[index] = links }
        }
        return details
    }

    internal fun parseListing(html: String, baseUrl: String, providerId: String): List<Candidate> {
        val profile = profiles[providerId]
            ?: throw IllegalArgumentException("Для этого сайта нет встроенного парсера")
        val document = Jsoup.parse(html, baseUrl)
        val candidates = LinkedHashMap<String, Candidate>()

        fun addCandidate(
            row: Element,
            title: String,
            pageUrl: String?,
            magnet: String?,
            torrentUrl: String?
        ) {
            val cleanTitle = title.replace(Regex("\\s+"), " ").trim().take(240)
            if (cleanTitle.isBlank()) return
            val identity = magnetInfoHash(magnet) ?: torrentUrl ?: pageUrl ?: cleanTitle
            val stats = parseStats(row)
            candidates.putIfAbsent(
                identity,
                Candidate(
                    cleanTitle,
                    pageUrl,
                    magnet,
                    torrentUrl,
                    row.text(),
                    stats.first,
                    stats.second,
                    stats.third
                )
            )
        }

        document.select("a[href^=magnet:]").forEach { anchor ->
            val row = resultContainer(anchor)
            val magnet = anchor.attr("href").takeIf { it.startsWith("magnet:", true) }
            addCandidate(row, titleFrom(row, anchor), firstDetailUrl(row, baseUrl), magnet, null)
        }

        document.select("a[href]").forEach { anchor ->
            val href = safeResolve(baseUrl, anchor.attr("href")) ?: return@forEach
            val path = runCatching { URI(href).rawPath.orEmpty().lowercase(Locale.ROOT) }.getOrDefault("")
            if (!path.endsWith(".torrent")) return@forEach
            val row = resultContainer(anchor)
            addCandidate(row, titleFrom(row, anchor), null, null, href)
        }

        val detailSelector = profile.detailSelectors.joinToString(",")
        document.select(detailSelector).forEach { anchor ->
            val title = anchor.text().trim().ifBlank { return@forEach }
            val href = safeResolve(baseUrl, anchor.attr("href")) ?: return@forEach
            if (href.startsWith("magnet:", true)) return@forEach
            val row = resultContainer(anchor)
            val rowMagnet = row.selectFirst("a[href^=magnet:]")?.attr("href")
                ?.takeIf { it.startsWith("magnet:", true) }
            val rowHash = magnetInfoHash(rowMagnet)
            if (rowHash != null && candidates.containsKey(rowHash)) return@forEach
            addCandidate(row, title, href, null, findTorrentLink(row, baseUrl))
        }

        if (candidates.isEmpty()) {
            document.select("tr, article, li").take(200).forEach { row ->
                val anchor = row.selectFirst("a[href]") ?: return@forEach
                val href = safeResolve(baseUrl, anchor.attr("href")) ?: return@forEach
                if (!isDetailLink(href)) return@forEach
                val title = anchor.text().trim()
                if (title.length < 3) return@forEach
                addCandidate(row, title, href, null, findTorrentLink(row, baseUrl))
            }
        }
        return candidates.values.take(MAX_RESULTS)
    }

    internal fun parseDownloadLinks(html: String, baseUrl: String): Pair<String?, String?> {
        val document = Jsoup.parse(html, baseUrl)
        val magnet = document.selectFirst("a[href^=magnet:]")?.attr("href")
            ?.takeIf { it.startsWith("magnet:", true) }
        val torrent = document.select("a[href]").firstNotNullOfOrNull { anchor ->
            val href = safeResolve(baseUrl, anchor.attr("href")) ?: return@firstNotNullOfOrNull null
            val path = runCatching { URI(href).rawPath.orEmpty().lowercase(Locale.ROOT) }.getOrDefault("")
            val label = anchor.text().lowercase(Locale.ROOT)
            href.takeIf {
                path.endsWith(".torrent") ||
                    path.contains("download.php") ||
                    path.endsWith("/dl.php") ||
                    (label.contains("torrent") && (label.contains("скач") || label.contains("download")))
            }
        }
        return magnet to torrent
    }

    /** Built-in tracker requests must stay on public HTTPS hosts, including after redirects. */
    internal fun isSafeTrackerRequestUrl(urlValue: String): Boolean {
        val uri = runCatching { URI(urlValue.trim()) }.getOrNull() ?: return false
        val host = uri.host?.removePrefix("[")?.removeSuffix("]")?.lowercase(Locale.ROOT)
            ?: return false
        if (!uri.scheme.equals("https", ignoreCase = true) ||
            uri.rawUserInfo != null || uri.rawFragment != null
        ) return false

        if (host.matches(Regex("[0-9.]+"))) {
            val parts = host.split('.')
            if (parts.size != 4 || parts.any { part ->
                    part.isEmpty() || part.length > 3 || !part.all(Char::isDigit) ||
                        (part.length > 1 && part[0] == '0')
                }
            ) return false
            val octets = parts.map { it.toIntOrNull() ?: return false }
            if (octets.any { it !in 0..255 }) return false
            val a = octets[0]
            val b = octets[1]
            val c = octets[2]
            val nonPublic = a == 0 || a == 10 || a == 127 || a >= 224 ||
                (a == 169 && b == 254) ||
                (a == 172 && b in 16..31) ||
                (a == 192 && (b == 168 || (b == 0 && c in 0..2) || (b == 88 && c == 99))) ||
                (a == 198 && (b in 18..19 || (b == 51 && c == 100))) ||
                (a == 203 && b == 0 && c == 113) ||
                (a == 100 && b in 64..127)
            if (nonPublic) return false
        } else if (!host.contains('.') && !host.contains(':')) {
            return false
        }

        if (host.contains(':') && (
                host == "::" || host == "::1" ||
                host.startsWith("::ffff:") ||
                host.startsWith("fe8", ignoreCase = true) ||
                host.startsWith("fe9", ignoreCase = true) ||
                host.startsWith("fea", ignoreCase = true) ||
                host.startsWith("feb", ignoreCase = true) ||
                host.startsWith("fc", ignoreCase = true) ||
                host.startsWith("fd", ignoreCase = true) ||
                host.startsWith("2001:db8", ignoreCase = true) ||
                host.startsWith("ff", ignoreCase = true)
            )) {
            return false
        }
        val privateSuffixes = listOf(".internal", ".intranet", ".private", ".corp")
        return !LocalNetwork.isLocalHost(host) && privateSuffixes.none(host::endsWith)
    }


    private fun fetchHtml(
        urlValue: String,
        cookie: String,
        originalHost: String,
        fallbackCharset: Charset,
        connectTimeoutMs: Int = CONNECT_TIMEOUT_MS,
        readTimeoutMs: Int = READ_TIMEOUT_MS
    ): HtmlPage {
        var current = urlValue
        for (redirect in 0..4) {
            if (!isSafeTrackerRequestUrl(current)) throw IOException("Трекер перенаправил запрос на небезопасный адрес")
            val uri = URI(current)
            val connection = (URL(current).openConnection() as HttpURLConnection).apply {
                requestMethod = "GET"
                connectTimeout = connectTimeoutMs
                readTimeout = readTimeoutMs
                instanceFollowRedirects = false
                setRequestProperty("User-Agent", USER_AGENT)
                setRequestProperty("Accept", "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8")
                setRequestProperty("Accept-Language", "ru-RU,ru;q=0.9,en;q=0.7")
                setRequestProperty("Cache-Control", "no-cache")
                if (cookie.isNotBlank() && uri.host.equals(originalHost, true)) {
                    setRequestProperty("Cookie", cookie.take(8_192))
                }
            }
            try {
                val status = connection.responseCode
                if (status in REDIRECT_CODES) {
                    if (redirect == 4) throw IOException("Слишком много перенаправлений трекера")
                    val location = connection.getHeaderField("Location")
                        ?: throw IOException("Трекер вернул перенаправление без Location")
                    current = URL(URL(current), location).toString()
                    continue
                }
                if (status == 401 || status == 403 || status == 429) {
                    throw IOException("HTTP $status от трекера. Проверьте Cookie или доступность сайта.")
                }
                if (status !in 200..299) throw IOException("HTTP $status от трекера")
                val bytes = connection.inputStream.use { readLimited(it, MAX_HTML_BYTES) }
                val html = decodeHtml(bytes, connection.getHeaderField("Content-Type"), fallbackCharset)
                return HtmlPage(connection.url.toString(), html)
            } finally {
                connection.disconnect()
            }
        }
        throw IOException("Не удалось получить страницу трекера")
    }

    private fun decodeHtml(bytes: ByteArray, contentType: String?, fallbackCharset: Charset): String {
        val headerCharset = Regex("(?i)charset\\s*=\\s*[\\\"']?([^;\\s\\\"']+)")
            .find(contentType.orEmpty())?.groupValues?.getOrNull(1)
        val prefix = bytes.copyOfRange(0, minOf(bytes.size, 8_192)).toString(Charsets.ISO_8859_1)
        val metaCharset = Regex("(?is)<meta[^>]+charset=['\\\"]?([a-z0-9._-]+)")
            .find(prefix)?.groupValues?.getOrNull(1)
        val charset = sequenceOf(headerCharset, metaCharset)
            .filterNotNull()
            .mapNotNull { name -> runCatching { Charset.forName(name) }.getOrNull() }
            .firstOrNull() ?: fallbackCharset
        return String(bytes, charset)
    }

    private fun readLimited(input: java.io.InputStream, maxBytes: Int): ByteArray {
        val output = ByteArrayOutputStream()
        val buffer = ByteArray(8_192)
        var total = 0
        while (true) {
            val count = input.read(buffer)
            if (count < 0) break
            total += count
            if (total > maxBytes) throw IOException("Ответ трекера превышает допустимый размер")
            output.write(buffer, 0, count)
        }
        return output.toByteArray()
    }

    internal fun ensureNotChallenge(html: String, trackerName: String) {
        val document = Jsoup.parse(html)
        val title = document.title().lowercase(Locale.ROOT)
        val explicitChallenge =
            html.contains("cf-chl-", true) ||
                html.contains("challenge-platform", true) ||
                document.selectFirst(
                    "form#challenge-form, form[action*=captcha], iframe[src*=captcha], " +
                        ".g-recaptcha, .h-captcha, #captcha, .captcha"
                ) != null
        if (title.contains("just a moment") || explicitChallenge) {
            throw IOException(
                "$trackerName требует браузерную проверку или CAPTCHA. Пройдите её в обычном браузере " +
                    "и добавьте Cookie-сессию; обход защиты не выполняется."
            )
        }
    }

    private fun resultContainer(anchor: Element): Element =
        anchor.closest("tr, article, li, .torrent, .result, .row, .gai") ?: anchor.parent() ?: anchor

    private fun titleFrom(container: Element, fallback: Element): String {
        val named = container.selectFirst(".detLink, .tLink, .torrent-name, .title, h2, h3")
            ?.text()?.trim().orEmpty()
        return named.ifBlank { fallback.text().trim() }
    }

    private fun firstDetailUrl(container: Element, baseUrl: String): String? =
        container.select("a[href]").firstNotNullOfOrNull { anchor ->
            val href = safeResolve(baseUrl, anchor.attr("href")) ?: return@firstNotNullOfOrNull null
            href.takeIf { isDetailLink(it) }
        }

    private fun findTorrentLink(container: Element, baseUrl: String): String? =
        container.select("a[href]").firstNotNullOfOrNull { anchor ->
            val href = safeResolve(baseUrl, anchor.attr("href")) ?: return@firstNotNullOfOrNull null
            val path = runCatching { URI(href).rawPath.orEmpty().lowercase(Locale.ROOT) }.getOrDefault("")
            href.takeIf {
                path.endsWith(".torrent") || path.endsWith("/dl.php") || path.contains("download.php")
            }
        }

    private fun isDetailLink(value: String): Boolean {
        val uri = runCatching { URI(value) }.getOrNull() ?: return false
        val path = uri.rawPath.orEmpty().lowercase(Locale.ROOT)
        val query = uri.rawQuery.orEmpty().lowercase(Locale.ROOT)
        return path.contains("viewtopic.php") || path.contains("details.php") ||
            path.contains("/torrent/") || path.contains("/topic/") ||
            query.contains("id=") && (path.contains("browse") || path.contains("details"))
    }

    private fun safeResolve(baseUrl: String, value: String): String? {
        val clean = value.trim()
        if (clean.isBlank() || clean.startsWith("#") || clean.startsWith("javascript:", true)) return null
        if (clean.startsWith("magnet:", true)) return clean
        return runCatching {
            val resolved = URL(URL(baseUrl), clean).toString()
            resolved.takeIf { isSafeTrackerRequestUrl(it) }
        }.getOrNull()
    }

    private fun parseStats(row: Element): Triple<Long?, Int?, Int?> {
        val rowText = row.text().replace(',', '.')
        val sizeMatch = Regex(
            "(?i)([0-9]+(?:\\.[0-9]+)?)\\s*(байт|bytes|kb|kib|mb|mib|gb|gib|tb|tib|кб|мб|гб|тб)"
        ).find(rowText)
        val size = sizeMatch?.let { match ->
            val amount = match.groupValues[1].toDoubleOrNull() ?: return@let null
            val unit = match.groupValues[2].lowercase(Locale.ROOT)
            val multiplier = when (unit) {
                "байт", "bytes" -> 1.0
                "kb", "kib", "кб" -> 1024.0
                "mb", "mib", "мб" -> 1024.0 * 1024.0
                "gb", "gib", "гб" -> 1024.0 * 1024.0 * 1024.0
                else -> 1024.0 * 1024.0 * 1024.0 * 1024.0
            }
            (amount * multiplier).takeIf { it <= Long.MAX_VALUE.toDouble() }?.toLong()
        }

        fun labelled(vararg patterns: String): Int? {
            for (pattern in patterns) {
                Regex(pattern, RegexOption.IGNORE_CASE).find(rowText)
                    ?.groupValues?.getOrNull(1)?.toIntOrNull()?.let { if (it >= 0) return it }
            }
            return null
        }

        val seedsByLabel = labelled(
            "(?:seeders?|seeds?|сид(?:ы|ов)?|раздач(?:а|и))\\s*[:=]?\\s*([0-9]+)"
        )
        val peersByLabel = labelled(
            "(?:leechers?|peers?|пиров|лич(?:ей|и)?)\\s*[:=]?\\s*([0-9]+)"
        )
        val seedsByClass = row.selectFirst(
            ".seedmed, .seed, .seeders, .seed-count, .seeds, [class*=seed]"
        )?.text()?.filter(Char::isDigit)?.toIntOrNull()
        val peersByClass = row.selectFirst(
            ".leechmed, .leech, .leechers, .peer-count, .peers, [class*=leech]"
        )?.text()?.filter(Char::isDigit)?.toIntOrNull()
        val numericCells = row.select("td").mapNotNull { cell ->
            cell.text().replace(Regex("[\\s\\u00a0]"), "")
                .takeIf { it.matches(Regex("[0-9]{1,8}")) }?.toIntOrNull()
        }
        val seedsByPosition = numericCells.getOrNull(numericCells.size - 2)
        val peersByPosition = numericCells.lastOrNull()
        return Triple(
            size,
            seedsByLabel ?: seedsByClass ?: seedsByPosition,
            peersByLabel ?: peersByClass ?: peersByPosition
        )
    }

    private fun magnetInfoHash(magnet: String?): String? {
        if (magnet.isNullOrBlank()) return null
        val encoded = Regex("(?i)(?:[?&])xt=urn:btih:([^&]+)").find(magnet)
            ?.groupValues?.getOrNull(1) ?: return null
        val hash = runCatching {
            java.net.URLDecoder.decode(encoded, Charsets.UTF_8.name())
        }.getOrDefault(encoded).trim()
        return hash.takeIf { it.matches(Regex("(?i)([a-f0-9]{40}|[a-z2-7]{32})")) }
            ?.uppercase(Locale.ROOT)
    }
}

package app.jacket.mobile.data

import java.net.URI
import java.net.URLEncoder

/**
 * Safe URL builder for user-configured website search links.
 * Results are opened in the external browser; arbitrary pages are not scraped.
 */
object WebSearchUrlBuilder {
    fun validateTemplate(template: String): String {
        val clean = template.trim()
        require(clean.isNotBlank()) { "Укажите URL поиска сайта" }
        require(clean.length <= MAX_TEMPLATE_LENGTH) { "URL шаблон слишком длинный" }
        require(clean.contains(QUERY_TOKEN)) { "В URL должен быть маркер {query}" }

        val probe = clean.replace(QUERY_TOKEN, "search-query")
        val uri = runCatching { URI(probe) }
            .getOrElse { throw IllegalArgumentException("Некорректный URL поиска", it) }
        require(uri.scheme.equals("https", ignoreCase = true)) {
            "Для сайта поиска требуется HTTPS"
        }
        require(!uri.host.isNullOrBlank() && uri.rawUserInfo == null) {
            "URL должен содержать домен и не должен содержать логин или пароль"
        }
        require(uri.fragment.isNullOrBlank()) { "Уберите фрагмент # из URL шаблона" }
        return clean
    }

    fun build(template: String, query: String): String {
        require(query.isNotBlank()) { "Введите название для поиска" }
        val clean = validateTemplate(template)
        val encoded = URLEncoder.encode(query.trim(), Charsets.UTF_8.name())
            .replace("+", "%20")
        val result = clean.replace(QUERY_TOKEN, encoded)
        require(result.length <= MAX_RESULT_LENGTH) { "Ссылка поиска слишком длинная" }
        val uri = URI(result)
        require(uri.scheme.equals("https", ignoreCase = true) &&
            !uri.host.isNullOrBlank() && uri.rawUserInfo == null
        ) { "Некорректная ссылка поиска" }
        return result
    }

    private const val QUERY_TOKEN = "{query}"
    private const val MAX_TEMPLATE_LENGTH = 2_048
    private const val MAX_RESULT_LENGTH = 4_096
}

package app.jacket.mobile.torrent

/** Strict Host header policy for the loopback-only media endpoint. */
object LocalStreamHostPolicy {
    fun accepts(hostHeader: String?, boundPort: Int): Boolean {
        if (hostHeader.isNullOrBlank() || boundPort !in 1..65535) return false
        val parts = hostHeader.trim().split(':', limit = 2)
        if (parts[0].trim().lowercase() != "127.0.0.1") return false
        if (parts.size == 1) return true
        val requestedPort = parts[1].toIntOrNull() ?: return false
        return requestedPort == boundPort
    }
}

package app.jacket.mobile.torrent

data class LocalStreamRoute(val token: String, val infoHash: String, val fileIndex: Int)

object LocalStreamRouteParser {
    private val tokenPattern = Regex("(?i)[a-f0-9]{32}")
    private val hashPattern = Regex("(?i)([a-f0-9]{40}|[a-f0-9]{64})")

    fun parse(requestTarget: String): LocalStreamRoute? {
        if (requestTarget.isBlank() || requestTarget.contains('\\')) return null
        val path = requestTarget.substringBefore('?')
        if (path.contains("%2f", ignoreCase = true) || path.contains("%5c", ignoreCase = true)) return null
        val parts = path.split('/')
        if (parts.size != 5 || parts[0].isNotEmpty() || parts[1] != "stream") return null
        val token = parts[2].takeIf { tokenPattern.matches(it) } ?: return null
        val hash = parts[3].takeIf { hashPattern.matches(it) } ?: return null
        val indexText = parts[4]
        if (!indexText.matches(Regex("[0-9]{1,9}"))) return null
        val index = indexText.toIntOrNull() ?: return null
        return LocalStreamRoute(token.lowercase(), hash.lowercase(), index)
    }
}
