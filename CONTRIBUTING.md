# Разработка Jacket

## Окружение

- JDK 17
- Android SDK Platform 36 и Build Tools 36.0.0
- Gradle 9.5.0
- Android Gradle Plugin 9.3.x
- Kotlin 2.4.21

## Проверки перед отправкой изменений

```bash
./gradlew testDebugUnitTest assembleDebug
```

Изменения в сетевом клиенте должны сохранять тайм-ауты, лимит тела ответа, запрет перенаправлений и проверку HTTP/HTTPS. Не записывайте API-ключи, magnet-параметры или приватные URL в логи.

Изменения в native-движке выполняйте в выделенном IO-контексте. Не передавайте JNI-объекты напрямую в UI; UI должен получать только неизменяемые snapshot-модели.

Для Android 15+ учитывайте ограничения длительности foreground service типа `dataSync`. Не обещайте непрерывную фоновую загрузку после исчерпания системного лимита.

- Предпочитайте небольшие, проверяемые изменения.
- Добавляйте unit-тесты для парсеров, моделей и форматирования.
- Обновляйте README и CHANGELOG при изменении пользовательского поведения.
- Не добавляйте секреты, tracker passkeys, ключи подписи APK или локальные конфигурации.
- В PR описывайте поведение, способ проверки и известные ограничения.
