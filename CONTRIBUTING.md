# Разработка Jacket

## Окружение

- JDK 17
- Android SDK Platform 36 и Build Tools 36.0.0
- Gradle 9.5.0
- Android Gradle Plugin 9.3.x
- Kotlin 2.4.21

## Проверки

```bash
./gradlew testDebugUnitTest assembleDebug
```

## Архитектурные правила

- Не добавляйте зависимость от внешнего Jackett-сервера или его API. Поиск должен выполняться через встроенные provider adapters.
- Новые индексаторы реализуйте через provider registry, а не через прямые вызовы из UI.
- Учитывайте условия использования, robots/rate limits и авторизацию каждого источника. Не добавляйте готовые списки несанкционированных трекеров.
- TMDB использовать только как источник метаданных и artwork; не трактовать его как источник видеопотоков.
- Не показывайте встроенное воспроизведение / download action для Archive item, если в его metadata отсутствует license URL.
- Сетевые вызовы выполняйте на IO dispatcher, ограничивайте timeout и размер ответа, не записывайте токены в логи.
- Не передавайте JNI-объекты в UI. UI получает только immutable snapshot-модели.
- Добавляйте unit-тесты для парсеров, нормализации ссылок и преобразования моделей.
- Для Android 15+ учитывайте ограничения длительности foreground service типа `dataSync`.
