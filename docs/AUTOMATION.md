# Автоматика: цикл улучшений каждые 6 часов

Воркфлоу **Auto improve** (`.github/workflows/auto-improve.yml`) запускается по расписанию в 00:23, 06:23, 12:23 и
18:23 UTC и вручную. За один запуск выполняется одно небольшое улучшение из `docs/BACKLOG.md`.

## Как это устроено

1. **Gate.** Запуск пропускается, если задана `AUTOMATION_PAUSED=true`, нет ключа доступа или уже открыто
   слишком много PR с меткой `auto-improve`.
2. **Агент.** Claude Code в раннере читает `.github/automation/program.md` и бэклог, выбирает один пункт, правит
   код и тесты, запускает `lint`, тесты и сборку. Пушить и открывать PR агенту не разрешено.
3. **Проверка воркфлоу.** Запрещённые пути (`.github/`, `gradlew*`, ключи) и слишком большой diff останавливают
   запуск. Затем воркфлоу сам повторяет `lint`, тесты и `assembleDebug`.
4. **PR.** Коммит в ветку `auto/...`, PR в `main` с меткой `auto-improve`, запуск CI. Вы принимаете PR вручную
   или включаете автослияние.

## Подключение (один раз)

1. Settings → Secrets and variables → Actions → New repository secret: `ANTHROPIC_API_KEY`
   (лучше отдельный ключ с лимитом расходов). Вместо него можно задать `CLAUDE_CODE_OAUTH_TOKEN`
   (токен из `claude setup-token`).
2. Actions → **Auto improve** → Run workflow. Первый запуск удобно сделать вручную и посмотреть результат; в поле
   `focus` можно указать тему.
3. Рекомендуется: Settings → Branches → правило для `main` с обязательной проверкой `verify` и обязательным PR.
4. Автослияние (по желанию): Settings → General → Allow auto-merge и переменная `AUTO_MERGE=true`.

## Переменные (Settings → Secrets and variables → Actions → Variables)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `AUTOMATION_PAUSED` | не задана | `true` — приостановить цикл |
| `AUTOMATION_MAX_OPEN_PRS` | 2 | сколько PR `auto-improve` может ждать проверки |
| `AUTOMATION_MODEL` | `sonnet` | модель агента (`sonnet`, `opus` или полное имя) |
| `AUTOMATION_MAX_TURNS` | 90 | предел шагов агента за запуск |
| `AUTOMATION_MAX_CHANGED_LINES` | 1500 | предел размера изменения |
| `AUTO_MERGE` | не задана | `true` — PR с `auto-improve` сливаются сами после зелёного CI |

## Ограничения

- Расписание GitHub работает по UTC, запуск может задерживаться; в публичных репозиториях расписание отключается
  после 60 дней без активности.
- Каждый запуск расходует токены API. Начните с ручного запуска и посмотрите стоимость в консоли Anthropic.
- Агент не меняет `.github/**`, ключи подписи и секреты; воркфлоу отклонит такой PR.
- Содержимое issues, PR и логов агент считает данными, а не инструкциями.
- Установка на устройство: пока APK берётся из артефактов CI. Подпись, nightly-релиз и проверка обновлений
  в приложении — пункт B-001.
